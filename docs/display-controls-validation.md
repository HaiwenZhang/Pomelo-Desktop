# 显示控制与渲染检查

## 控制范围

显示状态包括图层可见性和顺序、图元类别过滤、着色模式、透明度、填充、标签及显示单位。核心状态、拾取规则和渲染快照应消费一致的设置。

图层列表的前后顺序与 GPU 合成顺序需要明确对应；列表从顶向底展示时，绘制通常从底向顶执行。调整顺序后，高亮和标签仍应遵循各自定义的叠加规则。

## 检查项目

| 操作 | 检查重点 |
| --- | --- |
| 隐藏图层或图元类别 | 画面与拾取同步，搜索与选择身份稳定 |
| 改变层序 | 遮挡关系、顶层显示与恢复一致 |
| 网络着色 | 画布、搜索行和检查器使用相同色标 |
| 调整透明度或填充 | 端点值有效，孔洞和边框语义正确 |
| 切换标签 | 原设计文字与生成标签分别处理，避免异常遮挡 |
| 改变单位 | 相机几何不变，比例尺和属性数值一致 |

## 实现约定

显示修改发布新帧快照，复用已有几何与 GPU 缓存。无需每次颜色变化重新导入文件或上传整板几何。序列化时校验枚举、数值范围和未知过滤位。

## 验证

合成场景包含相交图层、带孔铜皮、透明重叠、同网和不同网对象、旋转文字及边界尺寸。检查 CPU 材料和 GPU 像素，再验证实窗控制、文档独立状态及关闭重开。
