# 诊断与后台任务反馈

## 数据契约

诊断保存严重度、稳定错误码、共享消息、对象身份及可用源位置。技术详情与主要说明分开；缺少位置时不伪造偏移。界面按当前语言格式化消息。

导入、场景准备和偏好保存分别报告进度与错误。失败原因应便于理解，不能只显示外部库的原始错误字符串。

## 展示与交互

长诊断和成员列表使用分页或虚拟化。折叠、页码和焦点由既有状态所有者管理，滚轮不应同时推动内外两层列表。语言切换更新诊断说明，保留必要技术字段。

选择对象、切换文档或更新诊断后，旧页内容不得覆盖新请求。取消提供明确结果，不将已取消任务报告为完成；完成反馈也不暗示已通过完整设计验收。

## 验证

覆盖空列表、单页、多页、长消息、未知对象、缺少位置、不同严重度与五语显示。检查键盘分页、折叠后焦点、内外滚动边界和快速切换。

启动阶段窗口尚未建立时仍需错误反馈；日志不可写时不能再次失去主要错误。公开复现信息只保留必要诊断，移除路径、设计名称和敏感属性。
