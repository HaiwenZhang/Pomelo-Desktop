# 诊断列表的实窗与分页验证

日期：2026-10-03。平台：Windows。继续 UI 优先开发，补充检查器文件信息中的真实警告状态；不代表完整产品或逐像素验收。

## 修复与组织

`panels/diagnostics.rs` 共用诊断页展示，检查器和工作台导入状态页保留各自的展开/页码及请求身份校验。页面只消费已受限的诊断迭代器，读取结构化消息并在当前语言渲染；严重程度、代码、偏移、对象 ID、源路径和技术详情保留。

滚动窗口固定为 192 逻辑像素；诊断行不可压缩，取消内容 `max_h` 限制，内部滚轮在外层边界停止传播。分页 ID 设置在真正持有滚动位置的 Scrollable wrapper 上。实测早期版本翻页后停在下一页末尾；修改后下一页从首条开始。分页栏允许换行。

分页命令使用 Kit 公开 Base Button 和应用持有的两个稳定焦点。进入首/末页后，被禁用的触发按钮把焦点交给另一侧可用按钮，避免焦点留在已移出 Tab 顺序的控件上。外观来自主题 token，使用标准 Enter/Space 点击行为；没有应用自定义按键模拟点击。诊断展示本身无 GPU 或 Windows API 依赖；这不构成新增 macOS/Linux 后端支持或构建验收。
