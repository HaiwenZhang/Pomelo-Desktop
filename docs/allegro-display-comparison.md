## 文字如何显示

以下数字是当前 Pomelo 实现的明确规则，不能据此声称已经恢复 Allegro 的全部内部算法。

- 源 PCB 文字与自动网络标注分别控制。源文字保留源内容、位置、方向和镜像；字体资源见 `pcb-text-font-provenance.md`。
- 自动标注默认来自每个可见层，并不只生成最上层文字。遮挡和叠加服从图层、对象类别的绘制优先级。Allegro 的实测局部画面也可见多个层的 GND 叠加；没有擅自通过全局避让删除下层文字。
- 走线：线宽投影至少 12 个逻辑像素，字高至少 8 像素；名称沿直线方向重复，重复间距至少 180 像素，并保持可读方向。
- 焊盘：名称适配各层焊盘长轴，字高达到 8 像素才显示；可以强制水平。不同层焊盘具有各自的尺寸和方向。
- 过孔：显示直径投影达到 22 像素才考虑跨度及名称；贯穿孔、盲埋孔开关独立。普通网络名按字高阈值裁剪，背钻名称有独立阈值。
- 铜皮：每个可见源区域最多生成 3 个候选名称，位于视口与该区域包围盒交集对角线的 25%、50%、75%。字号随交集宽度调整，低于 10 像素不生成；实际像素由铜皮轮廓及空洞 mask 裁剪，所以最终可见数量可能小于 3。
- 每次布局最多 65,536 个字形。超出时按前景图层优先保留完整名称，不输出半个名称，也不把整屏标注视为失败。
- Pan/Zoom 在后台合并布局请求；短暂复用的预览在相机稳定后更新。活动层过滤和类别开关变化使旧标注失效，不能靠旧缓存继续显示。

指定实板的实际窗口另外验证了全部 10 个铜层同时可见，并关闭“仅活动层网络标注”；从 516% 放大到 1527% 后，多个方向的 GND、焊盘网络名和跨度文字同时出现。初始保存视图只打开 TOP，且启用了活动层过滤，这两项查看设置会让画面看起来只有顶层标注，不能据此判断渲染器只支持顶层。当前验证窗口保留多层显示便于复查。

## 测量和导航

- 测量点保存在板的毫米坐标中；单位切换、缩放、平移与翻面不改变距离。
- Shift 临时限制水平/垂直，Alt 临时关闭吸附。Enter 完成折线，Backspace 撤回最后一点，Esc 退出工具并保留已完成的测量。
- 中键 Pan 可在测量过程中使用。相机变化后会重新计算光标下的实时测量预览。
- 一次拖动是一个历史步骤；连续滚轮事件以 250 ms 间隔分组。命名视图、搜索定位、Fit、翻面和区域 Zoom 不混入前一次滚轮步骤。
- 两点 Zoom 的第一点之后只保留预览，不继续捕获鼠标，因此工具栏和取消按钮仍可使用。

## 验证与边界

核心、应用和文字布局回归覆盖旧视图兼容、非法亮度、网格坐标、重叠多层标注、活动层跨类别过滤、缩放阈值与密集名称预算。HLSL 编译和 WGSL 验证通过。实际 D3D11 硬件像素读回验证了亮度通道、铜皮空洞中的标签裁剪及跨度/铜皮标注的独立透明度。


## 对象像素过滤补充

通过原版滑条的 End 操作，确认阈值最大为 100；0 时关闭过滤，类别复选框不可用。Pomelo 同样提供 0–100 的阈值，DRC 类别按任务范围不接入。

文字使用整个源文字的 em 高度判断，不能按单笔画长短或单个字符宽度删除部分字形。内嵌名称在后台布局中按字号判断。焊盘与过孔使用各自的显示尺寸；普通钻孔显示开关保持独立。铜皮按完整源区域判断，避免把经过视口裁剪后的局部大小误当成源区域大小。

空洞过滤只改变显示覆盖，不改源铜皮拓扑。普通三角网格保留每个独立孔的索引范围，曲线细分保留原始孔边界大小；过滤小孔时同时去掉其边界，拾取使用同一套可见轮廓。自定义焊盘内部孔与独立钻孔不冒充铜皮 Void。

真实 D3D11 回归覆盖了类别独立、Zoom 恢复、逻辑像素与 DPI、文字恢复不重传、普通与曲线铜皮空洞恢复。另有核心拾取回归覆盖有无解析轮廓两种源数据，验证小孔过滤后的显示覆盖与拾取一致。


在指定真实 BRD 的实际窗口中，将阈值从 0 调到 21，细小焊盘/过孔与内嵌网络名被过滤；单独取消焊盘类别后，焊盘恢复，其余类别继续过滤。验证后阈值恢复为 0。指定 BRD 另通过了生产限额下的完整导入和渲染准备测试。

跨度文字属于独立钻孔标注，仍由跨度开关与原有缩放阈值控制，不被“内嵌网络名”类别过滤。



## 填充图案补充

原版 Color Dialog 的 Layers 页显示 4×4 共 16 个图案选择器，颜色与图案各有独立应用开关。实测选择斜线图案后，Selected Composite 显示当前颜色和斜线的组合；观察结束使用 Cancel 关闭，没有应用临时改动。

Pomelo 在展开图层的 Etch、Pin、Via 颜色按钮旁增加图案菜单，支持实心、双向斜线、横竖线、不同密度点阵、虚线、交叉线、网格、棋盘、环、菱形及十字。菜单提供默认项，显示设置随该文档视图保存；“默认”恢复原先渲染策略，不表示已从 BRD 导入 Allegro 图案设置。

图案以视口左上角的逻辑像素为锚点，随 DPI 转换但不随板坐标放大，不改变铜皮几何或空洞。铜皮 mask 使用完整覆盖，透明图案像素不删除 stencil，因此铜皮网络名仍然连续并按真实轮廓裁剪；源文字、边界、钻孔及选择/悬停高亮不被填充图案打断。未填充的焊盘/过孔边界保持实线。

三个后端共享同一材质参数布局，统一上传透明度、亮度、对象过滤和 16 行图案位图；同时修正 WGPU/Metal 参数尾部未传递对象像素过滤的问题。Windows 上已执行 HLSL 编译、WGSL 布局验证及 D3D11 硬件读回；尚未在 macOS/Linux 实机验收。

SVG 使用屏幕像素密度的 mask，PNG 经过实际 SVG 解析和栅格化验证，覆盖 16 种图案、不同 Zoom、翻面及铜皮空洞。导出原有的源文字/自动标注缺失仍是单独限制，不能把图案导出验证等同于完整视口截图一致性。

在指定 AX7996A 实板窗口中，TOP 的 Etch 切为斜线，Pin 再单独切为竖线，Via 保持默认；画面中各类别独立变化，网络文字保持连续。重新打开菜单能看到当前勾选，方向键加 Enter 可以提交；验证后 Etch、Pin 均恢复默认。D3D11 专门回归也确认铜皮图案间隙中的网络文字仍连续，实际空洞裁剪不变。

本轮检查：核心 120 项、渲染常规 127 项、应用 104 项通过；41 项无需额外输入配置的硬件诊断通过（40 项批量通过，余下 1 项修正旧夹具后单独通过）。旧夹具的孔环标记、分页上传批次和网络高亮预期同步到现有规则；文字夹具移入真实空洞，以区分被上层铜皮遮住与文字颜色错误。需要额外字体/文本路径、性能样本路径及 S5000C 样本路径的 4 项诊断未计入通过数。格式与应用/渲染 Clippy 检查通过。

## 显示视图保存补充

继续通过 computer-use 打开 View → Net Visibility Manager，实际窗口标题为 Net Color View，显示 Visible rats、Colored nets 保存选项，Complete、Incremental、Toggle 恢复选项，以及 Show/Blank Rats、Highlight/Dehighlight 命令。Color Dialog 的 Nets 页则按 Net、Pins、Vias、Clines、Shapes、Rats 分类分配颜色。两者不应被误实现为单一的“隐藏整个网络铜皮”开关。观察后关闭工具，没有保存原版配置或源 BRD。

核对现有命名视图时发现，先前只保存隐藏图层和着色模式，因此恢复时会遗漏标注、图案、透明度、网格、过滤和各层类别设置。现改为保存完整 BoardDisplay，同时保留旧视图的恢复范围。嵌套显示设置使用与当前视图相同的数值和数量校验；恢复时重建颜色选择器状态，并更新光标下的测量预览。Fit 和前后视图导航也同步刷新测量预览。

核心回归覆盖“隐藏图层与着色模式没有变化，但其他显示设置需要恢复”的实际缺陷，并验证 JSON 往返、旧视图兼容、非法嵌套状态拒绝；122 项核心测试和 104 项应用测试通过，应用 Clippy 与格式检查通过。

实际 PCB 窗口中保存“多层标注查看”，随后关闭网格和焊盘填充、开启仅活动层标注。在图层可见性和着色模式保持不变时恢复该视图，三个显示设置和画面均恢复到保存状态，验证了旧实现会漏掉的场景。

另在当前显示关闭网格时正常退出并重启，确认文档当前状态仍为关闭网格，而“多层标注查看”的完整快照仍保存开启网格；重新打开该视图后网格恢复开启，验证快照和当前显示状态分别持久化。

## 网络分类颜色补充

原版 Nets 页实测：点击一行的 Net 色块，Pins、Vias、Clines、Shapes、Rats 同时采用所选颜色；单独修改 Pins 后，其他列保持原色；再次设置 Net 则重新统一各列。观察后使用 Cancel 取消，没有 Apply 或保存源板。

Pomelo 网络列表增加颜色设置入口，打开该网络的整网及四类颜色控件。整网设置统一各类别，随后类别颜色可以覆盖；清除类别覆盖时回到整网颜色，清除整网设置则恢复自动图层/网络着色。全局“显示自定义网络颜色”开关只临时隐藏赋色，保留配置。对象高亮组的颜色优先于网络赋色，选择/悬停反馈保持原有规则。

网络颜色作为文档显示设置随当前视图和命名视图保存。原始文字、自动名称、钻孔保持独立材质；铜皮空洞和填充图案不变。原版 Rats 分类与飞线可见性没有通过这一功能冒充实现，仍需后续接入。SVG/PNG 几何导出的四类网络颜色也使用相同优先级。

123 项核心、128 项渲染常规、104 项应用回归通过。41 项无需额外输入的 D3D11 硬件诊断通过，包括整网和各类别覆盖、两种自动着色模式、普通/自定义焊盘、独立钻孔与文字、透明度、隐藏及恢复颜色、几何不重传。需要额外字体/文本、性能样本及 S5000C 路径的四项诊断未计入通过数。核心/渲染 Clippy（含测试）及应用 Clippy 通过。

命名视图恢复同时同步颜色选择器和透明度、亮度、像素过滤滑条的内部值，避免数字已恢复而滑块仍停在旧位置。

指定实板窗口中，GND 整网设为绿色、Pins 单独设为蓝色；临时隐藏后恢复自动配色，再打开开关则恢复绿色/蓝色。保存“GND 配色”并正常重启，当前显示及命名视图保留了整网与分类 RGB。将全局透明度从 100% 调到 43% 后恢复该视图，画面、数值和滑块位置一同回到 100%。网络列表入口、调色板、分类覆盖与持久化均已通过实际窗口操作验证。

右侧面板折叠时，从网络列表打开颜色设置会自动展开面板并滚动到该网络的控件。分类控件使用统一的右侧色块/恢复按钮列，避免随标签长度横向漂移。

## Placement 动态位号补充

通过 computer-use 对照 Quickviews 的 Off、Placement: TOP 及多级 Zoom。原版在包裹绘图子类均关闭时仍显示元件区域内的动态 RefDes；开启 TOP 只临时打开 TOP Pin，保留原先 L3/L4 等其他层的可见性。手动关闭 TOP Pin 后，动态位号及放置边界仍在；Off 后消失并还原临时 Pin 显示。

同一连接器局部的实测中，J3302 横向、J3301 竖向，两者直接交叉重叠，没有全局避让。连续放大后字高随区域一起增长，没有小的固定像素上限。两者源丝印文字均为 90 度，说明动态方向不能直接复制源文字方向。当前 Pomelo 对两个轴分别计算适配字号；接近等大时优先较水平的方向（保留至少 90% 的可用字号），覆盖该实板对照案例。这是明确的近似排版策略，尚未声称还原原版全部内部算法。

导入器保留实际放置区域及其来源层，矩形旋转只作用一次，曲线与孔洞保留。指定实板 2,176 个元件中，2,107 个具有可用放置边界（TOP 939、BOTTOM 1,168），另 69 个未找到这类边界，主要为 SH 接触件；当前不补造焊盘包围盒。新增区域准备得到 12,728 个顶点、25,542 个索引。

图层面板增加 Quickview 菜单。动态位号不依赖 Board text、网络名称开关或“仅活动层网络标注”，按所选放置层显示；字高低于 8 个逻辑像素时不生成，达到阈值后随板坐标放大。保留重叠位号，实际区域及孔洞 stencil 限定文字覆盖，并绘制解析边界；不添加遮住电路的灰色区域填充。底面翻看时保持可读方向。模式和临时 Pin 状态包含在 Last 和完整文档/命名视图快照中。

新增 D3D11 硬件回归覆盖孔洞、区域外零渗漏、Off 立即隐藏旧缓存、重新开启不上传源几何；布局回归覆盖多级 Zoom、翻面、顶底层、隐藏源层、独立网络开关、重叠名称及近正方形方向。还修正导入 90 度浮点角度略越界导致阅读方向突然翻转 180 度的问题。124 项核心、131 项渲染常规、104 项应用测试通过，导入器全套测试通过；42 项无需额外输入配置的 D3D11 硬件诊断通过。需要额外输入的 4 项诊断仍未计入。格式、核心/导入/渲染（含测试）及应用 Clippy 通过。

实板窗口已验证 TOP 动态位号、从 2,729% 到整板 100% 再放大到 619%、关闭临时 Pin 后位号保留，以及所有基础图层隐藏时只临时显示 TOP Pin 与放置区域。近正方形方向修正后的最终窗口验收尚未完成：computer-use 在更新窗口绑定及重试后连续返回 `foreground window did not report a process id`，已停止界面输入；不能以通过代码回归替代这一项实机验收。

## 元件放置区域拾取

用户将本轮范围收敛为这一项，其余功能暂缓。放置区域以独立的 Placement 源身份参与拾取，解析到所属元件，不冒充 Pin 或 Zone。包围盒层次索引只作候选加速；精确判断使用原始旋转轮廓和解析圆弧，保留区域孔洞。

仅当前 Quickview 对应层的区域参与拾取。临时 Pin 显示关闭时区域仍可选；关闭 Quickview 后不可选，选中/悬停覆盖也停止绘制。复用既有前景排序、候选切换、Inspector、元件焊盘高亮与视图定位；没有焊盘或没有位号的元件仍保留源身份。拾取菜单明确显示“焊盘与元件放置区域”。

核心回归覆盖多级 Zoom、翻面、旋转区域包围盒空角、圆弧、孔洞、顶底层、Off、过滤、候选顺序、无位号元件及高亮保存身份。Inspector 验证区域选择不借用任意焊盘的网络信息。D3D11 像素读回验证边界的选中和悬停反馈、与同 ID 焊盘的类型隔离、孔洞内部保持空白及 Off 后不残留覆盖。指定实板生产限额准备通过，并抽取 16 个真实元件验证区域可形成独立拾取命中。
