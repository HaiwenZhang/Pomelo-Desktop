# 显示与交互语义

## 功能映射

| 查看命令 | Pomelo 行为 |
| --- | --- |
| View：Zoom By Points、Fit、In/Out、Previous | 保留滚轮光标锚点与拖框；增加两次单击框选、F11/F12；拖动 Pan、滚轮连续事件、翻面进入查看历史 |
| Display：Measure | 实时 ΔX、ΔY、距离、角度与投影虚线；详情补充曼哈顿距离；折线区分最后一段与总长 |
| Visibility：On / Off / Last | 增加可交换的 Last 快照，包含图层与 Etch/Pin/Via 类别掩码；Show all 同时恢复类别可见性 |
| Color/Visibility：Shadow mode | 增加活动层、非活动层亮度、同时调暗活动层；亮度作用于 RGB，与全局/铜皮 alpha 独立 |
| Color/Visibility：Grids | 增加板坐标点网格、颜色与间距，G 开关；小比例尺按 2 的整数幂抽稀，最大 16,384 个点 |
| Color/Visibility：Object filter | 增加 0–100 像素阈值，文字、过孔、焊盘、铜皮、空洞和内嵌网络名独立控制；填充、边界及拾取一致，Zoom 后重新判断 |
| 图层显示颜色 | 绘图层图形及其源文字可采用同一颜色覆盖；不修改源颜色 |
| Color Dialog：Nets 分类颜色 | 网络列表提供整网、走线、焊盘、过孔、铜皮颜色；可隐藏自定义颜色并恢复自动着色 |
| Color/Visibility：Available patterns | 各层 Etch、Pin、Via 独立选择 16 种屏幕图案；保留实际空洞及完整标注，不重建源几何 |
| 多层标注查看 | 默认保留全部可见层，另提供“仅活动层网络标注”；对走线、焊盘、过孔与铜皮统一过滤 |
| View：保存与恢复显示状态 | 命名视图保存相机及完整显示设置；旧视图兼容原先仅隐藏图层和着色模式的范围 |
| Visibility：Placement Quickviews | 按指定层显示动态元件位号及放置边界，独立于丝印；临时显示该层焊盘，Off 恢复原掩码 |

## 文字与标注

源文字保留字形、笔画、字高、间距、旋转与镜像语义。自动网络名称按图层和类别过滤，默认保留全部可见层；活动层过滤是独立显示选项。文字遵循对象绘制优先级，不通过全局避让删除下层名称。

文字覆盖与铜区、实际空洞及对象区域一致。显示样式和可见性变化复用源几何。颜色与透明度按各自设置计算；文字着色不能改变孔洞覆盖或对象身份。

## 颜色与图案

各层 Etch、Pin、Via 分别配置颜色与 16 种屏幕图案。图案间隙与实际几何空洞分开处理，网络文字保持连续。

网络外观支持整网和对象类别覆盖。整网设置可以统一各类别；单独覆盖某类别保留其他类别的颜色。隐藏自定义颜色时恢复自动配色，重新启用后恢复覆盖。显示状态及命名视图保存相应设置。

## Placement 动态位号

动态位号基于实际放置区域及其来源层，不直接复制丝印文字方向。对两个轴分别计算适配字号；接近等大时优先水平，并保留至少 90% 的可用字号。矩形旋转只作用一次，曲线与孔洞保留；缺失区域不使用焊盘包围盒补造。

Quickview 临时启用所选放置层及相应 Pin 显示，Off 后恢复原设置。位号不依赖 Board text、网络名称开关或活动层网络名过滤。低于 8 个逻辑像素时不生成文字，达到阈值后随板坐标缩放。底面查看时保持可读方向。重叠位号保留，由区域覆盖限定文字边界。

## 放置区域拾取

放置区域以独立 Placement 身份参与拾取，解析到所属元件。包围盒层次索引只加速候选查询，精确判断使用旋转轮廓和解析圆弧，并保留区域孔洞。

只有当前 Quickview 层的区域参与拾取。关闭临时 Pin 显示不关闭区域拾取；关闭 Quickview 后，区域及其选中、悬停覆盖退出画布。沿用候选切换、Inspector、元件高亮与定位；没有焊盘或位号的元件仍保留源身份。

## 回归方法

使用合成几何检查缩放、翻面、旋转包围盒空角、圆弧、孔洞、顶底层、显示过滤、候选排序和身份保存。GPU 像素回归分别检查图案、网络着色、位号覆盖、区域外零渗漏以及开关切换时的缓存复用。

```sh
cargo test -p pomelo-core --locked
cargo test -p pomelo-render --locked
```

CPU、GPU 与窗口交互分别验证；未执行的检查不计为通过。后续工作见 [显示与查看功能待办](display-rendering-backlog.md)。
