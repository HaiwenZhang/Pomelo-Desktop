# 检查器文件信息与诊断焦点验证

日期：2026-10-03。Windows，继续 UI 优先开发。范围是文件信息标题、诊断标题及诊断分页命令。

## 实现

`panels/focus_scroll.rs` 使用 GPUI 公开的 `ScrollHandle`、焦点作用域及布局回调，记录控件实际边界。焦点进入离屏命令时，在下一帧调整外层检查器的垂直偏移，只移动到命令完整可见的位置。焦点作用域不进入 Tab 顺序；没有新增应用级 Tab、Enter 或 Space 模拟处理器。

滚动状态由每个 `BoardViewport` 持有。外层保留 Kit 垂直滚动条，内容层按自然高度布局；诊断内部仍使用自己的独立滚动容器。文件信息和分页按钮预留透明边框，通过实际焦点状态显示主题 `ring`，不改变按钮高度。折叠与分页业务状态仍归文档视图所有。

实窗迭代发现两个问题并修复：直接把受限高度容器作为内容层会压缩底部分页；仅依赖 Base Button 的焦点样式未得到可见边框。现在保留自然高度内容层，并在展示层读取真实焦点来确定边框。未修改 GPUI 补丁或注册表依赖源码。

## 实窗结果

使用正式 importer 导入原创 `tests/fixtures/diagnostics-40.brd`，取得 40 条真实结构化警告，没有往 UI 注入假诊断。

- 简中浅色 1000×650：文件信息标题用鼠标聚焦后，可用 Space 展开；Tab 进入下方诊断标题时，外层自动滚动并显示完整标题。
- 英文深色 1000×650：Space 展开诊断，Tab 跳过禁用的上一页，直接进入下一页；外层自动显示完整按钮和焦点边框。包装作用域未增加 Tab 停靠点。
- Enter 从首页切到末页：显示源对象 42、偏移 6744，焦点转到上一页并显示边框；下一页禁用。
- 在内层警告区滚动到末尾：显示对象 49、偏移 7164、完整源路径；文件信息标题、诊断标题和分页位置保持不动，画布保持原位置与 2082% 标签。
- Space 返回首页：显示对象 10、偏移 4824，焦点转到下一页并显示边框。Shift+Tab 返回诊断标题。
- 最后补充的文件信息焦点边框在英文深色 1440×920 实窗复验：鼠标聚焦、Space 展开、Tab 进入诊断、Shift+Tab 返回文件信息，标题边框随真实焦点显示/清除。

最小窗口通过 Windows 系统菜单实际调整。没有把未完成的操作记录为通过。

## 2026-10-03 过滤、显示与窗口缩小补充

增加 `FocusScroll`，使用 GPUI 公开的 keyed state 保留动态命令的焦点作用域。接入四模式、定位/清除、标题清除、关联网络/元件、成员上一页/下一页、四种拾取过滤，以及显示面板的四个开关、透明度增减和恢复源顺序。作用域不增加 Tab 停靠点，命令业务仍由视口处理；成员卡片尚未接入两层滚动协调。透明度命令行允许整项换行。
