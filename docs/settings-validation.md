# 设置与偏好

## 行为

设置入口提供语言与外观选择，复用共享消息、主题及偏好服务。语言支持跟随系统和五种显式语言，外观提供浅色和深色主题。

菜单和快捷键通过同一个设置命令打开弹层。重复命令不应叠加对话框；关闭后焦点回到合理的原位置。显示单位属于文档查看状态，与全局语言及外观分别管理。

## 持久化

设置即时更新界面，同时通过已有后台保存流程写入偏好。启动 `--locale` 仅影响本次运行，不覆盖保存值。配置无法读取或写入时使用当前语言报告错误。

## 实窗检查

1. 从菜单和 `Ctrl+,` 打开，重复触发并确认只有一个弹层。
2. 逐项切换语言，检查菜单、提示、占位符和已打开文档。
3. 切换主题，检查文本、控件、焦点与画布。
4. 使用 Tab、方向键、Space 和 Escape 完成选择与关闭。
5. 正常退出后重启，检查保存值与跟随系统行为。
6. 在窄窗口、字体放大、后台导入及保存失败时重复检查。

源文件编码、设计名称和搜索内容不随界面语言改变。资源键一致性检查不能代替对话框布局及键盘行为验收。
