# 功能与操作

## 文件与文档

应用在本地导入文件并创建只读文档。可以通过打开命令、拖放或启动参数打开文件，使用文档标签在多个设计之间切换、关闭或重新加载。最近文件提供继续查看的入口。

导入覆盖取决于源文件版本及已保存的数据。遇到未支持对象或无效数据时，应查看导入诊断；不能以文件成功打开推断全部设计内容均已还原。支持的文件类型见[项目介绍](../README_zh-CN.md)。

## 查看与定位

- 平移、缩放和适应整板，用于浏览不同区域。
- 搜索网络和元件，选择结果并定位对应几何。
- 拾取对象、查看属性及组成员，按类别限制拾取范围。
- 切换显示单位，查看比例尺和几何数值。

搜索、选择和显示控制分别管理。定位范围需与实际显示几何一致，搜索结果的分组身份不等同于鼠标命中的单个图元。

## 显示控制

图层面板提供可见性和层序控制，显示选项用于调整图层或网络着色、铜皮透明度、焊盘填充以及文字标签。渲染覆盖走线、圆弧、焊盘、孔、铜皮和绘图等场景内容，具体效果取决于导入数据。

显示设置只改变查看方式，不写回设计文件。相关检查见[显示控制](display-controls-validation.md)。

## 2D 与 3D 统一查看

画布底部只有一条图标工具条，2D 与 3D 分组一致：视图（适配、框选缩放、翻面、上一个视图）、显示、工具（测量、框选、隔离、复制图像、长度表）。3D 右上角的视图立方体切换九个标准方向；显示模式分为默认、线框和实体，Z 拉伸可选只拉伸介质或连同金属一起拉伸，均只影响显示。

图层面板按导体层提供铜皮、走线、焊盘、过孔、元件五列，每格可填充、线框或隐藏，并支持逐层不透明度、可见性视图和单层模式（L，PageUp/PageDown 切换活动层）。网络页按名称推断差分对、总线和电源与地，支持正则筛选和逐网络显隐。

检查器为选中网络列出各层走线长度、过孔使用层段与残桩、相邻平面和引脚，并显示指针处每一导体层的内容。长度表比较选中网络与其差分对、总线或固定的网络；引脚间路径长度（Shift+L）沿走线和过孔计算。3D 支持两点和多段测量，层厚来自显示假设时读数会注明。长度均为二维中心线长度，推断结果与假设在界面中标明。设计与分阶段说明见 [2D / 3D 统一查看界面开发计划](viewer-2d-3d-unified-ui-plan.md)。

## 工作区与偏好

应用提供五种界面语言、浅色和深色主题、可折叠侧栏、多文档及查看偏好保存。界面语言与源文件编码相互独立，设计中的名称和文字保持原文。

常用快捷键包括 `Ctrl+O` 打开、`Ctrl+W` 关闭、`Ctrl+R` 重载、`Ctrl+K` 搜索、`F2` 适应整板和 `Ctrl+,` 设置。macOS 的应用快捷键使用 Cmd，具体绑定以应用菜单为准。

## 功能边界

当前定位是查看与检查，不包括设计编辑、布线、重新铺铜或 DRC；残桩、相邻平面和差分对等信息只作显示和推断，不给出规则结论。兼容性、显示精度、大型文件性能和跨平台稳定性仍需验证。后续计划与当前能力分开记录，不将规划项当作已交付功能。
