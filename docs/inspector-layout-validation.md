# 检查器密度、成员滚动与文件信息验证

日期：2026-10-03。平台：Windows；依据 `ui-design/02-workspace-light.png` 和 `01-workspace-dark.png`。本记录补充主 [UI 验证记录](ui-design-validation.md)，不代表逐像素一致或完整 MVP 验收。

## 实现

- 属性行与内容间距收紧；选择标题使用更明显的圆形色标；四种选择模式置于同一个带边框的圆角组中，保留自然文字宽度和窄栏换行。
- 连接对象使用 96 逻辑像素高的内部滚动窗口，默认显示两张卡片；真实数据仍按 256 项分页。默认窗口中定位/清除按钮直接可见。
- 修复成员滚动内容被 `max_h` 限制的问题：固定高度只约束滚动窗口，内容为垂直排列、不可压缩的成员卡片。内部滚动后的事件在外层边界停止传播，避免同时移动检查器。
- 拾取过滤增加分隔线；标题同步五语。文件信息展示提取至 `panels/file_info.rs`，使用 Kit `Collapsible` 和公开的 `base::Button` 组合，提供鼠标、Enter、Space、主题状态、可访问名称和展开状态。
- 固定版本的 Kit Accordion trigger 没有键盘焦点路径；实际按 Space 未展开后改用 Base Button 的标准交互。没有通过自定义按键模拟点击，也没有修改 GPUI 补丁。
- 文件信息展开状态归每个 `BoardViewport`；默认展开。内容读取实际场景统计和既有诊断，不使用设计图中的示例数量；本状态尚未写入磁盘。

## 实窗结果

验证使用真实只读源文件 `E:\brd_cases\LPDDR4_PGB.brd`。GND 源 ID 2035，825 走线段、234 引脚、319 过孔、4 铜皮，中心线总长 293.831411 mm；成员总数 1382，共 6 页。

| 操作 | 结果 |
| --- | --- |
| 简中浅色，1440×920，检查器顶部 | 属性双列、模式组和色标显示；前两张成员卡片为走线 12152、12149；定位/清除在默认可见区域 |
| 成员区域向下滚动 120 | 可见成员变为走线 8501 等后续对象；属性、分页、定位/清除及画布相机 177% 均保持原位置，外层检查器未同时滚动 |
| 下一页 | 页码从 1/6 变为 2/6；滚动位置回到页首，前两项为走线 9757、9758 |
| 在成员区域外滚动检查器 | 能到达拾取过滤和文件信息；成员分页与画布相机不变 |
| 文件信息鼠标、Space、Enter | 鼠标折叠，Space 展开，Enter 再折叠，箭头与内容状态对应；展开后可滚动到实际格式、统计和零诊断提示 |
| 日文、深色、1000×650 | 四模式完整换行；属性可自然换行；定位/清除各占一行并显示完整名称；过滤 Checkbox 整项换行，文件信息可达并可展开 |
| 窄窗口内部成员滚动 | 能移动到本页后续成员，定位/清除、过滤和文件信息的位置保持不变 |
| 同窗 USBC / LPDDR4 | USBC 文件信息折叠后打开 LPDDR4，其文件信息默认展开；Ctrl+Tab 返回 USBC 仍折叠，反向切回 LPDDR4 仍展开，两个文档的着色及相机也独立保留 |

实际文件信息为 Allegro BRD、4 图层、2430 线段、849 引脚、539 过孔、10 铜皮。左侧导航另含绘图层而显示 8 行，不能将其当作铜层数。

## 检查和边界

最终 Windows debug 构建通过；应用 51 项测试、i18n 资源/源码门禁 9 项、全工作区全目标全特性 Clippy `-D warnings` 通过。五语“拾取过滤”标签沿用已有消息契约并通过资源门禁；本轮实际检查简中和日文，其余语言工作区既有验证见 [五语记录](workbench-i18n-validation.md)。没有添加镜像布局的单元测试。

当前窄窗口的成员卡片正文允许省略，完整名称仍提供给可访问接口；尚未完成屏幕阅读器朗读、全部键盘焦点顺序、DPI/多显示器、所有对象长字段和全部五语操作流程验收。文件信息的同窗跨文档状态已实查，未将其声明为跨启动恢复。多条诊断的内部滚动现已另行验证，见 [诊断 UI 验证](diagnostics-ui-validation.md)。设计图中的成员为引脚示例，当前卡片保留真实源对象类别和 ID，没有伪造 U12/A17 等示例数据。

结束时保留 USBC 与 LPDDR4 两个真实文档，活动文档为 LPDDR4 / GND、177%；恢复默认 1440×920、语言跟随系统（简中）及浅色主题。
