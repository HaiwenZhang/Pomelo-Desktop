# 查看状态与退出恢复

## 状态与身份

查看状态保存相机、显示选项、选择和拾取过滤等文档偏好。窗口面板布局独立于各文档状态。持久化数据由 `services/prefs.rs` 管理，工作区捕获快照并协调后台保存。

恢复依赖源路径和内容身份匹配，并考虑格式和解码选项。文件内容或解码选项改变时，不应盲目套用旧对象身份。恢复选择须检查对象仍有效，不额外重新定位已恢复的相机。

## 保存与退出

关闭文档前捕获快照，正常退出捕获仍打开的文档。后台串行合并与原子替换避免多文档更新相互覆盖；退出等待最终任务，不依靠已经停止分发的 UI 回调完成保存。

未初始化视口不能生成无效相机快照。取消或过期任务不得让旧选择重新出现。损坏配置和保存失败保留诊断，不静默覆盖原有内容。

## 检查项目

- 状态序列化往返、旧字段默认值和未知值拒绝。
- 相机有限值及 GPU 可表示范围，透明度和类别位的边界。
- 两个文档的状态独立、连续保存合并和正常退出等待。
- 内容或编码变化后的恢复策略，恢复对象不存在时的处理。
- 配置损坏、路径不可写、原子替换失败和临时文件清理。
- 首次布局前关闭、快速重载、关闭及退出的任务时序。

单元测试之外，需实际修改视图、关闭重开、退出重启并复核画面。强制结束和超时行为单独验证，不能从正常退出结果推断。
