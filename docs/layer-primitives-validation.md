# 单图层图元过滤验证

日期：2026-10-03。当前范围为 Windows 的图层面板与正式 D3D11 合成绘制，不代表完整 UI 或 BRD MVP 验收完成。

## 行为与职责

图层名称用于展开/收起该行的“走线 / 过孔 / 焊盘”三个 Checkbox；眼睛图标独立控制整层显隐，排序仍由行尾菜单负责。首个源图层默认展开，同一文档一次只展开一行。展开态不改变 GPU 绘制顺序，也不修改源场景。

`pomelo-core::display` 新增稀疏的 `layer_primitives` 覆盖。三个类别默认可见；恢复默认后移除覆盖，旧视图文件缺失该字段仍正常读取。视图校验最多允许 4096 个覆盖项，配置错误继续使用五语诊断。过滤状态由现有文档快照、身份匹配及原子视图保存流程保存，不引入第二份配置。

走线开关只过滤该层业务走线，板框、绘图和文字保留各自原有控制。焊盘开关控制该层引脚焊盘，过孔开关控制该层过孔铜环；两者同时覆盖解析形状和自定义轮廓。铜皮保留原铜皮开关及不透明度。过孔钻孔在至少一个占用层可见且允许过孔时显示；所有占用层禁止过孔则隐藏。引脚实体钻孔继续受全局钻孔开关控制，不随单层焊盘开关消失。

核心参考拾取与索引拾取使用相同显示规则，在候选截断前排除隐藏图元。检查器对已选对象保留源信息和源统计；过滤不改变网络或元件的真实成员数量。

`pomelo-render` 在编码绘制时过滤已上传范围，自定义焊盘按类型化源身份过滤，保留原图层合成顺序及高亮规则。没有更改业务 Shader、实例 ABI、GPUI 补丁或生成缓存。

图层列表由等高 `uniform_list` 改为 GPUI `ListState`/`list`，支持单行展开后的不同高度。筛选或顺序变化重建列表索引；展开时仅失效旧行/新行的高度缓存。滚动条继续共用该列表状态，置顶/置底在新顺序建立后请求显示目标行。

## 自动及硬件证据

- 核心 85 项测试通过，包含 9 项 i18n 门禁；新增 3 项测试覆盖旧状态、独立类别、稀疏存储、多层过孔钻孔及覆盖项限额，现有混合拾取回归扩展至全部 8 种组合和候选上限 1/64。
- 应用 51 项测试通过；真实临时配置文件回归补充类别状态往返，并核对另一文档保持默认。
- 渲染库启用 `native-gpu` 后 65 项普通测试通过、4 项按原条件忽略；Windows debug 构建与工作区 Clippy 通过。
- 显式 D3D11 硬件测试 1 项通过，核对走线、解析焊盘、自定义焊盘、过孔铜环及钻孔像素；过滤恢复后整张像素数组一致，过滤期间走线/焊盘/自定义焊盘/钻孔的上传字节不增加。证据为诊断离屏目标，不能替代真实窗口帧率或显存释放验收。

硬件命令及原始输出：[layer-primitives-hardware-tests.log](gpu-validation/layer-primitives-hardware-tests.log)。必须启用 `native-gpu`；未启用时该测试不会编译，零测试不能计作硬件通过。


## Windows 实窗证据

使用最新 debug 程序和 `E:\brd_cases\LPDDR4_PGB.brd`。实际打开 BOTTOM 行后分别关闭走线、焊盘、过孔：对应紫色图元消失，铜皮填充和其他图层仍显示。恢复三个开关后画面恢复；输入 BOTTOM 可筛出并显示展开行，清空输入恢复完整列表。

在三个开关均关闭时 `Ctrl+W` 关闭文档，随后正常退出、重启、重新打开板：画布保持过滤结果，展开 BOTTOM 后三个 Checkbox 均未勾选。再恢复三个开关，保存并关闭测试文档。展开选择本身按首层重新初始化，不把它误称为持久化状态。

最新版本经系统菜单实际缩至 1000×650：英文 Traces/Vias/Pads 按完整词分两行，简中切回后恢复三个同排；图层名称及类型在空间不足时省略，名称 Tooltip 保留完整源文。图层列表实际滚动至末行，并在滚动后展开 BOTTOM，旧展开行高度正确收回；点击眼睛隐藏整层后三个类别仍保持勾选，重显恢复画面。最后恢复跟随系统及整层/类别显示。

本轮最初观察到英文最小宽度下检查器模式按钮存在省略；后续改为按自然文字宽度分配并换行，默认窗口及 1000×650 已复验完整标签与 Component/Object 点击。范围见 [UI 验证记录](ui-design-validation.md)，仍不扩大为完整五语工作区排版通过。
