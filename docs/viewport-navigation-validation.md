# Windows 视口导航实现与验证

日期：2026-10-02。走线/圆弧视口已接入平移、鼠标锚点缩放、适配整板与水平翻转。当前仍为走线预览；其他 PCB 图元及完整查看流程尚未完成。

## 行为与结构

`pomelo-core::interaction::ViewportNavigation` 保存各文档的相机与逻辑视口尺寸。初次布局和自动适配状态下随 resize 适配；用户平移或缩放后保留中心与比例，resize 不重置用户视图。适配命令重新进入自动适配状态，并保留翻转状态。无效尺寸、坐标和缩放参数不污染已有相机。

应用在 canvas prepaint 得到实际逻辑 bounds，更新导航状态后生成该帧相机。DPI 仅由 Windows GPU 后端将逻辑比例转换为物理比例。导航不改变共享场景、走线批次或 GPU 缓冲引用。

当前操作：

| 入口 | 行为 |
| --- | --- |
| 鼠标滚轮 | 以指针为中心缩放；支持行与精确像素 delta |
| 中键拖动 | 平移；释放按钮结束，未在画布开始的拖动不接管 |
| 画布获得焦点后的方向键 | 按视口尺寸的 10% 移动相机 |
| `+` / `=`、`-` | 以视口中心缩放 |
| `F` | 适配整板 |
| `B` | 水平翻转 |
| 标准按钮 | 适配、放大、缩小、翻转；命令后将焦点返回画布 |

命令、提示与欢迎页能力说明提供五语资源。按钮使用 GPUI Kit，翻转显示选中状态；画布具有键盘可见焦点边界，中键拖动显示 ClosedHand。布局沿用主题语义颜色、相对间距和可换行工具栏。导航键限定 BoardViewport 上下文，不接管搜索等其他输入区域。

## 已验证证据

- 全工作区 all-features 测试 227 项通过，1 项硬件测试默认忽略；Clippy 全目标/全部特性 `-D warnings` 和 Windows debug 应用构建通过。
- CPU 新增检查：正反面拖动与屏幕位移一致；手动视图 resize 后保持，重新适配恢复自动状态；无效输入不改变有效相机。既有鼠标锚点缩放、坐标往返与 fit 门禁继续通过。
- RTX 5080 硬件测试单独显式通过，使用与生产相同的导航控制器和 D3D11/HLSL 管线。初始 fit 与参考图像相同；缩放后走线锚点保持，向上平移 20 像素后走线中心从 y=93 到 y=73，原位置清空。
- 上述缩放/平移期间上传字节数、cache_builds 和 pipeline_builds 均未增加。机器记录见 [trace-navigation.json](gpu-validation/trace-navigation.json)。这是诊断离屏 CPU 回读，生产仍无全帧 CPU 回读。
- 新视口的最终构建真实 FPC 运行完成 394 个走线实例上传和 GPUI 呈现；相机中心为 (21.7295, 64.5125) mm，逻辑比例 3.428825485956101 px/mm。记录见 [navigation-fpc.json](gpu-validation/navigation-fpc.json)，应用 SHA-256 `8ddb82e096690a44c9797f285615fb1ef373b54e08bbc0f83217420ae6e79b9c`。这不证明输入事件的实窗验收。

## 尚未验收

Computer Use 可以捕获欢迎页和文件对话框，但对话框没有独立可操作窗口；键盘输入未进入可见文件名字段，无法继续打开案例并操纵画布。未使用其他 UI 自动化绕过，也未将数学或离屏检查称为真实窗口交互通过。

仍需实窗验证按钮/键盘派发、Tab 焦点、菜单返回、拖出画布后释放、多文档相机保留、五语长文案、最小窗口及深浅主题。当前样式按设计指南完成代码检查，真实尺寸/焦点验收仍未完成。平移、缩放性能也未形成 release 指标；GPU 图元范围见 [走线验证](gpu-trace-validation.md)。
