# 导航、搜索与选择

## 实现边界

核心层负责相机数学、搜索、分组与拾取索引；应用视口负责输入、显示快照和后台任务适配。检查器显示对象属性和组成员，渲染层消费高亮集合。

鼠标命中的几何、搜索结果的组身份和定位时的完整范围是不同概念。定位使用所选目标的有效几何范围，不能用某个命中图元代替整个对象。

## 相机检查

- 平移后坐标投影和反投影一致，缩放保持光标锚点。
- 适应整板包含全部有效几何，退化或空范围不会产生非法缩放。
- 高 DPI、窗口调整和侧栏变化后视口比例正确。
- 极大中心、极小缩放等无效状态不能转成 GPU 无穷值或零缩放。

## 搜索与拾取检查

名称排序、大小写、数字段及非拉丁字符使用稳定规则。组成员聚合应有稳定身份，分页不能漏项或重复。隐藏图层和类别过滤影响可拾取范围，选择定位不应清空用户过滤。

快速变更查询、切换文档或取消任务后，旧结果不得覆盖当前内容。长结果集使用虚拟化或分页，离屏焦点命令应滚动到可见范围。

## 验证入口

```sh
cargo test -p pomelo-core --test camera_navigation --test search_scene --test search_collation --test component_groups --locked
```

实际窗口补验鼠标、键盘、搜索定位、分页、焦点恢复和多文档切换。核心测试通过不代表输入事件和 GPU 高亮接线已验收。
