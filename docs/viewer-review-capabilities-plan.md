## 范围决定

### 纳入的两个阶段

| 阶段 | 目标 | 纳入内容 |
| --- | --- | --- |
| 第一阶段 日常审阅闭环 | 找到对象，选择和比较，测量距离，保留重点并输出结果 | 两点测量、对象净距、任意多选、多组持久高亮、自定义颜色、截图与轻量审阅导出、命名视图、导航历史、框选放大，以及 Web 已有的显示控制补齐 |
| 第二阶段 工程信息基础 | 理解对象的属性、焊盘结构、物理叠层和连接关系 | 通用属性、对象条件查询、完整焊盘栈检查、物理叠层、网络层级、已有飞线、连接拓扑和指定路径长度 |

这里的“完整”指明确列出的用户任务形成从数据到操作再到结果的闭环，不意味着支持所有 Allegro 数据库版本、所有对象类型或所有格式。每项功能必须公开其实际支持范围。

### 明确不纳入

以下内容是用户排除的范围，不作为第三阶段或第四阶段留在本计划中，也不作为前两阶段验收的隐含依赖：

- 读取和浏览已保存的 DRC、豁免 DRC、短路检查结果，以及自行运行 DRC。
- 约束集合、约束继承与覆盖解析、最终生效规则、约束来源和电气规则检查。
- 设计完成度、未放置或未布通统计、铜皮孤岛或浮铜诊断，以及 DRC、铜皮、背钻是否过期的状态审查。
- 3D 查看、切面、碰撞分析、二维和三维联动。
- 独立双视口分屏及高级并排审阅。
- 批注、评论、批注层交换、协作审阅。
- 操作录制、宏、脚本回放及自动化审阅。

PCB 编辑、布线、重新铺铜、修改约束、写回原始板文件、SI/PI 求解也不属于本计划。

多格式导入和新平台开发不因本次对照而增加为任务。原总计划中已有的相关远期安排不在此重写；本文新增交付面向当前 Windows 桌面版和 Allegro 数据链路。

### 容易混淆的边界

| 纳入功能 | 边界 |
| --- | --- |
| 对象净距 | 计算几何距离，不读取设计间距规则，不判定合规或违规 |
| 网络层级 | 展示源文件中真实存在的分组和成员关系，不解析这些分组对应的电气约束 |
| 连接拓扑和飞线 | 展示连接关系及已有连接记录，不输出设计布通完成率或 DRC 结论 |
| 物理叠层 | 展示厚度、材料、层序和源文件提供的参数，不求解阻抗或做规则检查 |
| 通用属性 | 展示实际读取的属性与已知来源，不实现完整约束解析器 |
| 焊盘栈 | 展示逐层定义和已读取的热焊盘数据，不重新计算规则驱动的热连接 |
| 审阅导出 | 导出图像、选择信息和测量结果，不增加批注系统或协作平台 |
| 命名视图 | 保存相机和查看设置，不等同于批注、分屏或版本比较 |

## 第一阶段 日常审阅闭环

本阶段尽量复用现有几何、拾取和查看状态能力。以下条目均为待开发或待补齐，不以表格存在作为完成标记。

### A1 两点测量

提供明确的测量入口，支持在画布上选择两个点，显示直线距离、水平差、垂直差、角度和曼哈顿距离，并支持连续折线的累计距离。能够结束当前测量、重新开始、取消和清除结果。

测量结果使用源空间坐标，支持 mm 和 mil。自由点与吸附点需有可识别的状态；首批吸附范围至少包括线端点、焊盘或孔中心，后续对象类型按实际算法覆盖声明。

验收要求：已知坐标的结果正确；翻板、缩放和平移不改变物理数值；单位切换只改变表达；取消不遗留半完成状态；测量不修改原始设计。

### A2 对象间净距

支持选定两个对象，显示其最近点和边缘最短距离。引脚和过孔可同时展示中心距。首批覆盖直线走线、圆弧、常见解析焊盘和孔；自定义焊盘和铜皮外边界及孔洞也属于本阶段目标，但应在各自算法验收后启用。

净距计算必须考虑线宽、焊盘实际形状、旋转、镜像、偏移和铜皮孔洞，不能用包围盒距离或中心距冒充。优先基于指定的共同物理层计算；多层对象允许选择层。无共同层时不得默认给出具有电气含义的净距。

相交、接触、包含、无共同层和不支持类型应有明确结果。只报告几何事实，不报告“符合规则”。几何近似算法需要说明容差，容差不得随着屏幕缩放变化。

验收要求：用解析参考值和专项合成案例覆盖上述边界；最近点与绘制轮廓一致；同一对象对在不同缩放、DPI 和翻板状态下保持一致。

### A3 任意多选与属性比较

在现有对象、走线、网络、元件四种模式之上增加任意选择集合，支持追加、移除、清空及批量选择查询结果。框选需要明确采用完全包含还是相交规则，并向用户保持一致。

检查器展示数量、共同属性和不同值，区分当前主对象与整个集合。重叠候选切换、单个对象选择和整网选择不能互相污染。相同对象经多个入口选中后只计一次。

验收要求：跨对象类型和跨层多选正确；集合变化及时更新检查器；已隐藏对象保留或移除的策略明确且一致；取消异步查询后不出现旧结果覆盖新选择。

### A4 多组持久高亮与颜色覆盖

让高亮独立于当前选择保存。用户可以把对象、网络或元件加入高亮组，设置名称和颜色，逐组显隐、删除，并清除全部高亮。查看新对象时不丢失原有重点。

提供网络和图层颜色覆盖、单项恢复默认与全部恢复默认。需要制定对象覆盖、网络覆盖、层色、持久高亮、当前选择和悬停的显示优先级，保证几种状态仍可辨认。默认不依赖只有颜色才能识别的反馈。

验收要求：同网跨图元着色一致；清除选择不清除持久高亮；恢复默认不修改来源颜色；不同文档之间不串色；颜色和高亮恢复受文件身份校验约束。

### A5 显示控制补齐

接通现有标签选项：走线网络名、引脚网络名、过孔网络名、铜皮网络名、通孔标签、盲埋孔跨度标签。板文件原始文字与自动生成标签保持独立控制。

补充全局透明度、全局元件焊盘和过孔焊盘开关、当前层选择，以及层与对象类别的显示优先级。保留现有铜皮透明度和逐层类别控制。显示优先级只影响视觉覆盖，不改变真实物理层序。

不同图元对全局透明度和铜皮透明度的继承策略必须明确，不能简单相乘导致与现有 Web 语义不符。显示变化同步影响适用的拾取和标签，不留下不可见但可误选的对象。

验收要求：每个开关均有实际渲染反馈；状态按文档保存恢复；恢复默认有效；调整顺序、翻板和切换当前层不改变物理层信息；不为单纯显示变化重新解析整板。

### A6 命名视图与导航历史

在已有“恢复上次状态”之外提供多套命名视图。视图至少保存相机、翻板、显隐、显示优先级、颜色和标签设置；用户可以创建、覆盖、重命名、删除和恢复。

导航历史支持返回上一视图和前进，记录搜索定位、适配、框选放大和完成后的手动导航。连续滚轮或拖动应合并为合理的历史步骤，不能每帧产生一个节点。

视图与源文件身份关联。文件内容或解码方式改变时，不盲目恢复旧对象引用。命名视图与高亮组引用的持久化边界需在实现时固定并测试；不要求直接兼容 Allegro 的 `.color` 文件。

验收要求：保存和恢复的画面状态一致；前进后退行为可预测；窗口尺寸变化不破坏恢复；同一文件多文档会话的策略明确；旧版配置可迁移或被清晰拒绝。

### A7 截图与轻量审阅导出

提供画布截图入口，支持当前视口和整板范围，至少输出 PNG，并提供是否包含测量标记、选择和高亮的选项。结果应包含用户当前关注的可见内容，而非直接截取整个应用窗口。

轻量审阅导出包含板文件标识、单位、选中对象摘要和测量结果，以及可关联的截图。具体文本或表格格式在实现时选定，必须可由用户直接阅读。输出只写入独立文件，不嵌入源板数据库。

此项不包含完整打印排版、打印机管理、PDF 报告系统、批注编辑或批注交换。若以后需要这些能力，另行确认范围。

验收要求：导出图片与相同显示配置一致；尺寸、文字和透明度正确；导出的测量值包含单位和测量类型；用户取消不写入半成品；输出失败可重试且不影响当前文档。

## 第二阶段 工程信息基础

本阶段需要扩展数据语义。不能只增加空面板，也不能用图元数量或网络名称推测未读取的工程信息。

### B1 通用属性

建立可关联到稳定对象 ID 的属性模型，支持字符串、数值、布尔、带单位数值及明确的缺失状态。保留来源名称和来源对象信息；已知的直接属性与继承属性应区分，未解析的继承关系不能伪装成已知。

检查器支持查看、筛选和复制属性。保留现有常用几何字段，避免让常用信息淹没在原始记录中。属性比较复用 A3 的选择集合。

验收要求：保留原始字段含义和单位；未知、不适用、未支持与数值零分开；不凭空补值；来源定位可追溯；大批量属性读取可以取消。

### B2 对象条件查询

扩展网络和位号搜索，至少覆盖引脚、过孔、走线、铜皮、元件和通用属性。支持对象类型、网络、图层、名称或位号、属性以及适用的数值条件，并提供结果数量与可浏览列表。

典型任务包括查找某层的指定网络走线、某孔径范围的过孔、某位号的引脚，以及具有某属性值的对象。结果可定位、追加到选择、加入高亮组，并在检查器中查看。

查询不包含 DRC 或约束条件。数值比较必须明确单位，名称过滤和数值过滤不能混用字符串比较。

验收要求：结果完整或明确提示分页与截断；无结果和不支持条件可区分；查询取消和快速切换不返回过期结果；列表支持大数据量浏览而不阻塞界面。

### B3 焊盘栈检查

从当前孔径、焊盘几何和过孔跨度信息扩展到按物理层查看焊盘栈。目标信息包括名称、层范围、逐层形状和尺寸、偏移和旋转、钻孔或槽孔、镀孔属性，以及实际读取到的反焊盘和热焊盘定义。

提供二维逐层预览或简化截面表示；此处截面仅用于表达焊盘栈和层关系，不属于 3D Viewer。已有背钻信息可显示起止层、保护层和孔径，但不判断其是否过期或重新分析背钻。

验收要求：分别覆盖通孔、盲孔、埋孔、槽孔、自定义焊盘和背钻案例；源定义与实例放置变换区分；未读取的热焊盘数据明确显示为未知或不支持；逐层详情与画布一致。

### B4 物理叠层

建立物理层序、导体和介质、厚度、材料、源文件提供的介电参数及区域叠层关系。图形显示顺序与物理层序必须独立。对刚柔或多区域设计展示真实区域与叠层的关联，不因已有区域编号便声称完整支持。

支持查看层表和二维结构示意，并从过孔或焊盘栈定位相应层。源文件未提供厚度或材料时明确标注，不能默认赋值制造完整外观。

验收要求：完整数据下总厚度与层厚求和一致；数据缺失时不输出确定总厚度；层 ID、名称和物理位置对应正确；切换显示优先级不改变叠层；不同区域不混用层序。

### B5 网络层级

保留源文件实际定义的网络组、网络类、总线、差分对、匹配组和 XNet 及其成员。不能仅凭 `_P`、`_N` 等命名规则生成“已确认差分对”。

允许从组向下查看成员、定位、选择、着色和持久高亮。一个网络属于多个组时，其颜色和对象身份保持一致，计数需要去重。缺少来源支持时显示普通网络，不生成虚假的层级。

验收要求：组成员与来源记录一致；空组、重复成员和多重归属处理明确；选组可准确展开到成员对象；不顺带实现对应的约束检查。

### B6 飞线与连接拓扑

读取并展示源文件已有的连接记录，提供全部、指定网络和指定元件的飞线显隐。区分逻辑连接、已布铜几何和来源飞线，不能把同网所有引脚间的连线都称为真实未布连接。

构建可查询的连接拓扑，为 B7 路径查看提供基础。拓扑优先利用源数据的真实连接关系；需要几何推导的部分必须记录方法、容差和适用对象。不同层之间只能通过已支持且有效的跨层连接关联，不能因为平面投影交叉就认定导通。

铜皮、热连接、孔层跨度和不完整解析都会影响连接判断。未覆盖时应标记拓扑不完整，不输出设计布通完成率或“没有未连接”的结论。

验收要求：同层相连与断开、跨层投影交叉、有效过孔、铜皮孔洞、分支和孤立对象分别验证；显示开关不改变真实连接关系；隐藏层不会被当作不存在。

### B7 指定连接路径和长度

复用 B6 的拓扑，在两个对象或端点之间查找并高亮连接路径，显示路径包含的线段、层变化、过孔数量及二维中心线长度。遇到多路径时允许选择分支或指定途经点，不把任意找到的一条路径当作唯一答案。

保留现有网络铜线总长统计，并明确区分三种概念：集合的铜线总长、选定路径的二维长度、电气长度。前两项在本范围内，电气长度和延迟计算不纳入。

不将过孔深度、铜皮中的假定直线距离或键合线二维投影自动算作真实三维长度。对于无法可靠求解的连接段，应给出不完整原因，而不是拼接一个看似精确的值。

验收要求：直线、圆弧、分支、回路、多层路径、断开路径和不完整拓扑均有案例；路径高亮与统计对象一致；重复对象不重复计长；单位转换正确；大网络路径搜索可取消。

## 数据与实现约束

### 工程信息与渲染几何分离

现有 `BoardScene` 适合作为不可变渲染场景继续使用。新增工程信息应通过稳定对象 ID 与场景关联，避免将属性、网络组和拓扑反复复制到每个 GPU 图元。具体类型和文件拆分在实现设计中确定，本文件不强制尚未验证的类名。

| 模块 | 主要责任 |
| --- | --- |
| `pomelo-import` | 读取真实属性、焊盘栈、叠层、网络分组和连接记录，输出结构化来源与缺失信息 |
| `pomelo-core` | 测量几何、选择集合、查询条件、工程信息模型、连接拓扑、路径与查看状态契约 |
| `pomelo-render` | 测量标记、多组高亮、颜色覆盖、标签和透明度策略、导出所需画布绘制 |
| `pomelo` | 工具入口、检查器和查询交互、命名视图、导航历史、本地导出与状态生命周期 |

### 正确性约束

- 几何测量使用源空间双精度数据，不使用 GPU 像素坐标作为物理尺寸依据。
- 每个查询、测量或连接结果都能对应到对象身份、物理层和必要的来源信息。
- 无法解析、缺失、不适用、空集合和零值分别表达。
- Web 是实现参考和差分对象，不是所有工程语义的最终正确性依据。
- 颜色、显隐和当前选择不会改变源设计数据或真实网络连接。
- 保存状态需要考虑源内容变化、编码变化、对象失效和配置版本迁移。

### 平台与交互约束

延续现有 Windows、GPUI Kit、D3D11/HLSL 和五语国际化边界。新增功能按用户任务组织，不要求输入 Allegro 命令，不照搬其对话框和固定快捷键。

保留现有工作区和原生应用设计方向。具体布局、组件、快捷键及视觉样式在对应功能实施时按仓库适用设计规范制定；本计划只固定能力和操作结果。

后台查询和重计算必须支持取消并拒绝过期结果。高亮、查询和标签状态按文档隔离。大板界面采用适当索引和虚拟列表，显示设置变化不触发无关的整板解析或几何重建。

## 实施顺序与依赖

下表是两个阶段内部的建议批次，不增加用户已排除的第三或第四阶段。

| 批次 | 工作内容 | 前置关系 | 交付证明 |
| --- | --- | --- | --- |
| 第一阶段基础 | A5 显示控制，A3 选择集合的数据契约 | 现有显示和拾取基础 | 开关、保存恢复、集合操作实窗记录 |
| 第一阶段测量 | A1 两点测量，A2 对象净距 | 几何与拾取，A3 的双对象选择 | 数值参考案例及画布标记验证 |
| 第一阶段保留重点 | A4 持久高亮，A6 命名视图与历史 | 稳定对象身份和版本化状态 | 跨选择、跨会话、跨文档隔离验证 |
| 第一阶段输出 | A7 截图与轻量审阅导出 | 测量、选择、显示状态 | 可阅读输出文件和画布一致性证据 |
| 第二阶段属性 | B1 通用属性，B2 条件查询 | 来源解析和对象身份，A3 | 属性对照样本和查询结果验证 |
| 第二阶段结构 | B4 物理叠层，B3 焊盘栈 | 层身份及来源定义 | 逐层与区域对照样本 |
| 第二阶段网络 | B5 网络层级，B6 飞线与拓扑 | 来源关系和稳定对象身份 | 成员、跨层连接和断开案例 |
| 第二阶段路径 | B7 指定路径与长度 | B6，复用 A1/A2 的结果表达 | 分支、回路、断开及不完整结果验证 |

阶段内可以交错实施，但没有可靠拓扑时不得提前宣布路径测量完成；只有层名称时不得宣布物理叠层完成；已有渲染参数但没有用户入口和恢复机制时不得宣布显示控制完成。

不在本文件估算工期。解析工作量依赖来源字段、版本和样本覆盖，应先完成专项调查再安排。

## 验收与完成标准

### 验证层次

1. 几何与数据验证：解析参考值、单位、层身份、集合去重、拓扑连接及缺失语义。
2. 真实样本验证：选择包含目标对象的板文件，对照源数据或官方工具显示结果，记录来源版本和样本指纹。
3. 渲染验证：高亮、轮廓、最近点、文字和导出图像一致，必要时使用硬件像素验证。
4. 实窗交互验证：入口、键盘与鼠标操作、取消、错误恢复、多文档和保存重开。
5. 性能验证：小板和大板分别记录查询耗时、交互响应、取消响应与内存变化，基于实际测量确定门槛，不预填虚假通过值。

### 第一阶段完成条件

- A1 至 A7 的用户入口和结果链路均可实际使用。
- 测量数值正确且说明单位、层与算法支持范围。
- 任意多选、持久高亮和临时选择互相独立。
- 命名视图、历史和新增显示设置可按设计保存恢复。
- 可输出独立可读的截图和审阅数据。
- 通过相关回归、实窗和五语验证，没有损坏现有看板流程。

### 第二阶段完成条件

- B1 至 B7 已实现明确支持范围内的数据读取、用户查看和交互。
- 属性、叠层、焊盘栈和分组均有来源证据，不用推测代替解析。
- 对象查询可处理真实大板，结果可选中、定位和高亮。
- 飞线、拓扑和路径输出区分已知、不完整和不支持。
- 无任何 DRC、约束合规或设计完成度结论作为此阶段交付。
- 每项功能都有对应样本、检查记录和未覆盖范围。

### 验收记录格式

每项功能完成时记录功能编号、源码版本或工作区指纹、样本指纹、数据来源、操作步骤、实际结果、支持范围和未覆盖项。新增专项验证文档链接回本文；状态由证据更新，不根据计划批次自动标为完成。
