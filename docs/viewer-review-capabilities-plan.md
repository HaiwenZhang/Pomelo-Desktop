# 审阅能力规划

状态：待开发或待补齐。本文按 Pomelo 的用户任务组织功能，当前实现需以代码和验收结果核对；不因模型中存在字段就认定功能已交付。

## 第一阶段：日常审阅闭环

目标是从找到对象、保留重点到测量和输出结果，形成可重复的本地审阅流程。

| 优先级 | 功能 | 用途与交付范围 |
| --- | --- | --- |
| 高 | 两点和折线测量 | 直线距离、水平与垂直差、角度、累计长度，支持 mm/mil |
| 高 | 对象净距 | 两个对象的最短二维几何距离，展示最近点和连接线 |
| 高 | 任意多选 | 追加、移除、框选、清空和集合统计，独立于网络或元件分组 |
| 高 | 持久多组高亮 | 保存多组关注对象，可命名、隐藏、改色和删除 |
| 高 | 命名视图与导航历史 | 保存关键区域及显示状态，支持前进、后退和快速返回 |
| 中 | 自定义显示 | 图层和网络颜色覆盖、标签分类、透明度及显示优先级 |
| 中 | 框选放大 | 指定矩形范围放大，支持取消并返回原视图 |
| 中 | 截图与轻量导出 | 本地输出当前视图、测量和选中对象摘要，明确包含内容 |

### 测量

自由点与吸附点应有可识别状态。首批吸附考虑线端点、焊盘和孔中心，扩展对象按实际覆盖声明。两点测量与折线测量分别提供开始、结束、取消和清除操作。

对象净距基于有效二维几何，明确边框、填充、孔洞和隐藏对象的计算范围。交叠或接触返回零距离；不支持对象给出明确提示。

验收使用已知几何：平移、缩放和窗口变化不能改变物理数值，单位切换只改变表达。净距属于几何测量，不作设计规则合规判断。

### 选择与高亮

选择集合、当前悬停和持久高亮分别管理。网络和元件展开可加入选择集合，清除当前选择不应删除持久组。数量较大的集合采用分页或虚拟化。

持久组保存稳定对象引用及颜色，源文件改变后检查引用有效性。显示失效成员，不静默将旧引用绑定到其他对象。颜色之外仍需名称或状态提示。

### 视图与显示

命名视图保存相机及约定的显示状态，导航历史记录明确的定位操作，不记录每次鼠标移动。源内容改变后的恢复策略应可理解。

自定义颜色提供恢复默认值。标签分类、透明度和图元显示优先级需有独立设置及持久化定义，不能仅添加入口而缺少渲染接线。

### 输出

截图应选择当前视口或指定范围，处理背景、尺寸、比例尺和选中标记。输出前让用户了解文件名、路径及包含内容。

轻量导出优先覆盖测量和选择摘要，编码、单位及来源说明稳定。导出失败不破坏已有文件，不修改源设计；共享前可移除设计名称和敏感属性。

## 第二阶段：工程信息基础

目标是理解对象结构与连接关系。以下能力依赖源文件实际提供的数据，缺失值明确显示为未知。

| 优先级 | 功能 | 用途与交付范围 |
| --- | --- | --- |
| 高 | 通用属性与条件查询 | 按类型、图层、网络、元件及已读属性筛选，结果可定位 |
| 高 | 焊盘逐层结构 | 查看逐层形状、孔、镀层及已读取的相关定义 |
| 中 | 物理叠层 | 展示物理层序、厚度、材料和来源参数 |
| 中 | 网络分组 | 浏览真实分组和成员关系，与网络搜索联动 |
| 中 | 连接拓扑与已有飞线 | 展示连接记录、分支和断开关系，标明数据来源 |
| 中 | 指定路径长度 | 在选定端点和分支间计算长度，与网络累计长度分开 |
| 中 | 查询模板与表格输出 | 保存筛选条件，列选择、排序和本地 CSV 输出 |
| 后续 | 显示预设 | 命名图层和显示组合，支持恢复、更新及来源有效性检查 |

### 属性与查询

保留属性名、值、单位及来源，不能用显示字符串替代类型化数据。查询支持清空、取消和稳定排序，长结果集分页；表格选择、画布定位及检查器应指向同一对象。

查询模板持久化条件与列设置，不缓存旧查询结果。CSV 使用明确编码和转义，输出内容可预览；源数据更新后重新执行查询。

### 焊盘与叠层

逐层检查器分别展示铜形、孔与其他已读取结构，明确不存在与未读取的区别。叠层按源数据展示厚度和材料，未知参数不推算成确定值。

这些功能不重新计算工艺规则、热连接或阻抗。预览的单位、比例和层序需与画布及属性一致。

### 连接与路径

连接拓扑使用源对象身份及真实连接关系，不能仅凭视觉相交猜测电气连接。已有飞线只表示读到的连接记录，不作为布通完成率或规则结论。

路径长度需处理分支、环、多个可选路径和无连接情况。先明确路径，再计算长度；区分二维中心线、孔段及缺少物理参数时的未知部分。

## 范围与完成标准

当前规划保留以上两个阶段，不增加规则检查、约束求解、3D、独立双视口、协作、操作录制或脚本审阅。设计编辑、布线、重新铺铜和源文件写回不属于此计划。

每项功能应交付完整操作闭环、五语消息、状态恢复与失败处理，使用合成数据验证算法，并在实际窗口核对键盘、焦点、性能及取消。实施契约见[审阅开发设计](viewer-review-development-design.md)。
