# 工作区五语排版与检查器操作验证

日期：2026-10-03。当前只验证 Windows 原生窗口，案例为 `E:\brd_cases\LPDDR4_PGB.brd`。本记录补充 [UI 设计落地](ui-design-validation.md)，不代表全部 UI、DPI 或 BRD MVP 验收完成。

## 本轮改动

- 图层的走线、过孔、焊盘 Checkbox 保留 GPUI Kit 的交互和尺寸 API，改为自然宽度、禁止项内换行，空间不足时由父容器整项换行。取消英文 62 / 其他语言 48 逻辑像素的猜测宽度，修复最小左栏中日文“パッド”被拆开的问题。
- 检查器在真实成员卡片后加入主色定位按钮，与轮廓样式的清除按钮组成操作区，位置对应设计稿。依据当前选择显示“定位网络”等名称，无选择或正在定位时禁止重复定位；清除仍允许取消正在进行的定位。复用现有 `locate_target` / `clear_selection`，没有第二套选择或相机逻辑。
- 图层/网络着色按钮的选中项采用主题主色，与设计稿中的明确选中状态一致；保留互斥语义和既有真实 GPU 绘制入口。
- 画布左上角显示“全板 / 当前源名称”，无源名称时显示“全板”；空间不足时省略，完整名称仍可在检查器查看。名称来自真实选择详情，不翻译源网络、元件或引脚名称。
- 新增 `LocateSelected(kind)` 和 `BoardSelection(name)` 消息契约，英文、简中、繁中、日文、韩语资源同步；完整语句经 rust-i18n 格式化，没有拼接翻译后的句子。

## 实窗证据

使用正常构建的 `target/debug/pomelo.exe`，默认 1440×920，另经 Windows 系统菜单调整到最低 1000×650；最低尺寸下左栏约 200、右栏约 240 逻辑像素。
