## 标签溢出与键盘焦点补验

在独立 Release 窗口同时打开 `SS8633A_AMPB_FPC_DOE_V2_HVT_A_0423_1716.brd`、`15X15_REF_LPDDR4X_32X1_S6L_V1_0_0729_1727.brd`、`17x17_REF_DDR4_16X2_S4L_V1_0_0704_1326.brd`，文件来自只读 `E:\brd_cases`。三个长标签在 1000 逻辑像素宽度下产生真实横向溢出。

修复前，Ctrl+Tab 激活离屏文档能够自动滚动，但从中间关闭按钮按 Tab 到末尾关闭按钮时，标签行没有滚动，焦点环在屏幕外。应用现有 `FocusReveal` / `FocusScroll` 增加显式横向模式，每个标签包裹一个不参与 Tab 顺序的焦点范围；原检查器仍使用默认纵向模式。焦点变化或滚动区尺寸变化时，按对应轴在下一帧显示聚焦的标签，不在 prepaint 中直接修改偏移。包装后仍保持一个文档对应一个直接滚动子项，Workbench 的 `scroll_to_item` 索引不变；没有修改 GPUI、Kit、Shader 或五语文案。

新版 Release 在简中深色 1000×650 实窗完成以下检查：

| 检查 | 实际结果 |
| --- | --- |
| 反向导航 | Ctrl+K 聚焦搜索；Shift+Tab 经过平移、选择、打开文件、文档菜单，再到三个关闭按钮。末尾按钮和焦点环自动显示，回到首项时首个标签完整显示 |
| 正向导航 | 从首个关闭按钮连续 Tab 到中间、末尾和菜单，末尾标签再次自动滚入，焦点环可见；当前文档没有因焦点导航而切换 |

这些证据补齐三个标签的双向 Tab、活动项溢出滚动和菜单取消恢复；不表示完整应用焦点顺序、关闭按钮的 Enter/Space 激活、其他四语最低窗口、DPI/多显示器或逐像素对比已验收。仅缩窄窗口且焦点位于画布时，不保证自动拉回活动标签；活动切换、键盘聚焦和菜单仍是可达入口。

## 文档标签进一步对齐设计稿

本轮使用独立的 Windows Release 窗口验证，保留用户正在操作的 debug 窗口。活动标签由绿色文字改为普通前景色加半粗体；标签增加顶部及两侧边框、顶部主题圆角、非活动表面和横向间距，标签行按 2.5 rem 排列。侧栏标签仍使用绿色选中态。

`workbench/document_tabs.rs` 使用 GPUI Kit 公开的 Base `Tab` / `Tabs` 组合文档外观，继续使用 Kit `Tag`、`Button`、`DropdownMenu` 和 `PopupMenuItem`。Tab 保留可访问名称、选中状态及位置；文档菜单新增 `DocumentNavigation` 五语消息。文档生命周期、关闭、快捷键和横向 `ScrollHandle` 仍由 Workbench 持有，激活时调用 `scroll_to_item`。不修改 Kit 或 GPUI 补丁。

## 此前实现

- 已导入的文档标签从实际 `PreparedBoard.source.format` 显示格式徽标，当前为 Allegro；未导入时不推断格式。文件名保持源文，单标签上限为 24 rem，超长时省略，格式徽标和关闭按钮仍可见，溢出菜单保留完整标签。
- 关闭按钮使用 `CloseNamedDocument(name)` 可访问名称，五语消息契约和资源同步。适应整板按钮的可访问名称改为动作名称，原先错误地使用了 F2；打开文件与适应整板按钮分别显示 Ctrl O / F2 提示，继续调用原有命令。
- 修复长文件名把原生最小化、最大化、关闭按钮挤出最低宽度的问题。仅给标题文字添加截断不足以约束 Kit 标题栏内部的固有最小宽度；应用内容区现在按照窗口宽度减去 Kit 控制按钮的实际数量及宽度进行约束。保留标准 TitleBar、拖动行为与 Kit 控制按钮，没有修改 GPUI 缓存或 vendor。
- 此阶段拾取过滤使用 48% 的最小列宽，允许长名称占用自然宽度并整项换行。后续已移除固定最小列宽、按设计顺序自然排列，当前实现及字体范围以 [侧栏记录](sidebar-style-validation.md) 为准。
- 新增应用层 `tooltips.rs`：通过 Button 公开的 `InteractiveElement::interactivity().tooltip(...)` 注册提示，使用 Kit Tooltip 外观与 GPUI 元素所属的生命周期。替换应用中的按钮提示入口，长源路径限制为 24 rem 并换行。避免 Kit 管理的 overlay 在所属按钮移除后仍显示旧提示；没有访问 Kit 私有窗口状态或维护第二套 overlay。
- 画布悬浮工具栏对齐设计图：深浅主题均使用深色画布命令表面、浅色文字/图标、绿色选中态与分组线，按钮尺寸为 2 rem；通过父容器居中，不再猜测负偏移。颜色集中在产品 theme 层，通过 Kit 的 `ButtonCustomVariant` 定制，保留原按钮交互。命令区阻止左键、中键按下及滚轮事件继续传给下方画布，修复工具栏操作意外清除真实选择的问题。
