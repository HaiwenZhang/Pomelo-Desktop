## 实现

`welcome/recent.rs` 使用 `Presentation::{Sidebar, Continue, All}` 明确三个展示区域。开始页“继续上次查看”和侧栏仅展示最近三项；“查看全部”及侧栏“最近文件”显示持久化历史的完整列表，仍受既有 20 项上限约束。预览限制不删除历史记录。

主区标题使用 20 逻辑像素半粗体和底部分隔线，“查看全部”保留标准 Kit Button，主色文字及箭头按文字在前、箭头在后排列。主列表保留行分隔线，侧栏取消逐行分隔线。源文件名允许两行，超长时在第二行末尾显示省略号；可访问名称和原有路径提示仍保留完整内容，格式与真实层数为次级文字，日期使用 14 逻辑像素文字。

完整列表的父容器使用纵向 flex 和有界可用高度，列表填充剩余空间。三个区域分别为 **Scrollable wrapper** 指定稳定 ID；仅给内部 Div 设置 ID 不足以隔离 Kit 的滚动状态。避免同一渲染调用位置产生共享 ScrollHandle，使完整列表的偏移影响开始页或侧栏。开始页整体仍可滚动，窄窗口下拖入区与继续查看区纵向排列。

展示选择由 Workbench 协调，打开、重定位和移除继续调用正式命令；路径、编码、预览及磁盘保存仍归 services。没有加入示例数据或新消息，五语继续通过共享 i18n 入口显示；当前只宣传已支持的 Allegro BRD。
