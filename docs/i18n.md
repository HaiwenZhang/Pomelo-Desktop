# 国际化

应用支持 `en`、`zh-CN`、`zh-TW`、`ja`、`ko`。共享消息契约位于 `crates/pomelo-core/src/i18n.rs`，翻译资源位于 `locales/`，应用语言切换位于 `crates/pomelo/src/i18n.rs`。

- 新增消息时同步注册语义键、参数和五种语言的译文。
- 五种语言保持相同的键及命名占位符，避免拼接可翻译句子。
- 后台任务保存结构化消息，展示时按当前语言格式化。
- 源文件名、图层名、网络名、元件标识和设计文字保持原文。
- 界面语言与文件编码分别设置；启动参数 `--locale` 仅覆盖本次启动。

修改后执行共享资源测试，并检查目标语言下的实际界面、布局和输入行为。通用命令见[开发与验证](development-progress.md)。

## 消息与诊断

`MessageKey` 注册稳定语义键及完整参数名；结构化消息保存键和参数，界面在展示时选择语言。诊断保留错误码、严重度、对象身份及可用的源位置，技术详情与主要说明分别展示。

外部错误字符串不代替应用主要文案，源名称也不参与译文占位符的递归替换。数量、单位和日期按共享格式处理，避免把已经翻译的字符串长期缓存到文档状态中。

## 切换与偏好

语言偏好可以跟随系统或显式选择五种语言之一。启动 `--locale` 覆盖与已保存偏好区分处理；界面切换刷新菜单、工具提示、输入占位符和现有文档面板，不清空搜索或改变设计文字。

系统对话框自带标签可能跟随操作系统语言；应用提供的标题、说明和命令使用当前应用语言。

## 验证

```sh
cargo test -p pomelo-core --test i18n_resources --test i18n_source --locked
```

检查五语键与参数一致、资源修改触发重新编译以及嵌入消息可格式化。实窗还需覆盖长译文、窄侧栏、字体放大、非拉丁输入和切换后的焦点；资源测试不代表五语布局均已验收。
