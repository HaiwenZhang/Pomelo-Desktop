# i18n 开发契约

当前国际化基础使用锁定的 `rust-i18n 4.2.4`。应用和无窗口 CLI 共用 `pomelo-core` 初始化的资源；支持 `en`、`zh-CN`、`zh-TW`、`ja`、`ko`，英文为运行时 fallback。资源编译进程序，离线可用。本文约束后续全部界面、解析器、后台任务、GPU 和系统诊断开发。

2026-10-03 UI 补齐继续遵守此契约：最近日期以时间戳保存，按当前语言和当地日历生成消息，不缓存翻译文本；层数、图层类型、检查器属性名与 PNG 准备/加载诊断从实现起同步五语。源名称作为独立属性值呈现，不解析译文里的冒号或递归替换源文占位符。预览损坏诊断保留结构化路径与独立技术详情，不影响原文件打开入口。

## 资源和模块

启动错误的五语原生反馈位于 `services/startup_error.rs`。在窗口创建前按有效的命令行语言覆盖、保存偏好、系统语言、英文的顺序选择语言；错误主要原因和独立技术详情在展示时格式化。日志不可写也使用共享消息，不以第三方错误字符串替代主要文案；原生标题、正文及关闭按钮已加入源码门禁。实现与实窗范围见 [启动错误验证](startup-error-validation.md)。

- `locales/{en,zh-CN,zh-TW,ja,ko}.yml`：平铺的语义键，`_version: 1`，五语键和命名占位符必须一致。
- `crates/pomelo-core/src/i18n.rs`：`Locale`、`LanguagePreference`、`MessageKey` 参数注册表、结构化 `Message` 及显式语言格式化。
- `crates/pomelo-core/build.rs`：跟踪共享 `locales/` 目录，保证仅修改译文也触发编译；测试逐键对照源文件与嵌入资源，防止旧二进制译文误通过。
- `crates/pomelo-core/src/model.rs`：`Diagnostic` 保存稳定错误码、消息、严重度、源偏移/对象/路径、独立技术详情。
- `crates/pomelo/src/i18n.rs`：应用语言状态、组件同步、应用菜单重建、串行后台保存；退出等待最后一次保存。
- `crates/pomelo/src/prefs.rs`：平台配置目录 `Pomelo/language.json`，版本化 JSON、有界读取、同目录临时文件与原子替换。无配置使用系统语言；损坏配置不自动覆盖，展示可翻译诊断，重新选择语言可修复。

Windows/Linux 使用 Kit `AppMenuBar` 显示应用菜单；`set_menus` 后同步 Base 的菜单快照，语言 revision 改变时重新加载菜单实体。macOS 的系统菜单路线仍需实机验证。系统标题栏、文件对话框自带标签遵循 OS 语言；应用提供的对话框命令文案使用所选语言，不改变 Windows 的系统语言。

启动解析“显式偏好 → 系统语言 → 英文”。系统语言归一化支持 `_`/`-`、大小写和常见编码后缀；中文优先识别 `Hans/Hant`，再识别 `CN/SG` 与 `TW/HK/MO`，裸 `zh` 为简中。保存值只允许 `system` 和五种规范 locale。

桌面 `--locale` 可为本次启动覆盖界面语言，不保存偏好；`--encoding` 独立控制该次进程的源文件解码，不随界面语言变化。当前视口导航按钮和操作提示同步五语；欢迎页能力说明已改为实际支持的 BRD 导入与走线预览，避免保留旧文件头阶段文案。

## 新增消息的步骤

1. 在 `MessageKey` 注册稳定语义键及完整参数名，例如 `UnsupportedMagic => "import.allegro.unsupported_magic" ["magic"]`。
2. 在五个 YAML 中同时添加自然译文和相同的 `%{magic}` 占位符；不要拼接前缀、数量和后缀。
3. 底层返回类型化错误，在集中映射中生成 `Diagnostic`，附带源位置和机器参数。`thiserror::Display` 只用于技术代码/详情，不作为用户提示。
4. 无参数标签使用 `text(locale, key)`；有参数消息使用 `Message::new(key).arg(name, value).display(locale)`。后台和 CLI 总是显式传入 locale，不调用全局 `set_locale`。
5. 添加语义测试，运行资源与源码检查。新增用户消息的功能没有五语资源就不能计为完成。

保留诊断结构，展示时执行 `diagnostic.message.display(locale)`；不能在任务完成时把 `error.to_string()` 存入文档状态。已有错误、任务阶段和标签可重新格式化，切语言不重新导入场景。原始网络名、reference、路径、写入器信息和板文字保持原值；源文件编码与 UI locale 无关。

`Message::render` 检查缺少/多余参数并返回类型化格式错误；展示入口遇到参数问题使用可翻译应急提示。替换只执行一次，源名称中的 `%{...}` 保持原值。数值与单位目前采用明确的工程格式；需要日期、区域数字或复杂复数时先补共享格式规则和测试，不假定库提供完整 ICU/CLDR。

## CLI 和报告

```powershell
cargo run -p pomelo-import --bin pcb_inspect -- --locale ja --help
cargo run -p pomelo-import --bin pcb_inspect -- --locale zh-TW probe E:\brd_cases\example.brd
cargo run -p pomelo-import --bin pcb_inspect -- --locale ko check --stage header --cases-dir E:\brd_cases --report .cache\headers.jsonl
cargo run -p pomelo-import --bin pcb_inspect -- --locale ja --encoding windows-1252 check --stage index --cases-dir E:\brd_cases --report .cache\indexes.jsonl
```

`example.brd` 是用法占位文件名，请替换成真实路径。CLI 的 `--locale` 可置于命令前或后；不指定时人读消息默认英文，以便脚本复现。报告 schema version 为 3：`error` 为结构化诊断，`locale` 和 `localized_message` 为展示字段；新增 `encoding`、可选索引摘要和证据路径。调用方不能继续把 `error` 当成字符串，也不能依据译文判断结果。报告明确 `stage: header/index`，汇总保持 `scene_validated: false`。

源编码由 `--encoding utf-8|gbk|shift_jis|big5|windows-1252` 显式选择，默认严格 UTF-8；不能由 `--locale` 推断编码。无法解码、重复字符串/记录键、未知/未对齐/非法记录、未支持的布局及索引预算错误均保留类型化参数与源偏移，并有完整五语译文。全文本编码与案例对照范围见 [BRD 索引验证](brd-index-validation.md)。

`decode-fixed FILE --records JSON --report JSONL` 与 `decode-records FILE --records JSON --report JSONL` 使用独立的请求/字段报告 schema version 1；后者包含固定及变长布局。请求绑定源 SHA-256、大小和 span；JSONL 中 `fields` 为源字段，`error`、`locale`、`localized_message` 与头部/索引报告遵循同一诊断契约，stage 为 `fixed-records` / `records`。新增解码预算及引用缺失/类型/循环错误同步五语；字段与错误参数不随 locale 改变。验证范围见 [记录解码验证](brd-record-decoder-validation.md)。

`decode-geometry` 沿用同一 SHA-256 绑定请求，JSONL 首行是图层/比例 metadata，后续行包含路径或轮廓、结构化诊断及显式 locale；不宣称完整 scene 验证。单位、无效几何和几何预算错误同步五语。图层缺失名称在展示时用 `board.layer.default_name` 格式化，源名称不翻译，切语言不重建几何。验证范围见 [几何验证](brd-geometry-validation.md)。

`decode-padstack` 沿用同一请求契约，输出定义预览、引脚/过孔引用解析及背钻参数，最后一行保留去重的结构化 warning 和当前语言文案。缓存预算、无效尺寸、无效圆环与未支持几何同步五语；warning 身份、源 key/offset 和参数不随语言变化。完整放置和整板场景尚未完成，范围见 [焊盘验证](brd-padstack-validation.md)。

## 检查和审校

原生设置页新增 7 个共享消息键（五语共 35 条译文），覆盖入口、标题、语言/外观分组、编码独立性帮助、即时生效说明与关闭命令。打开的弹层按当前 locale 重译，偏好错误在所属分组展示。组件默认关闭图标的英文可访问名称在此页面通过隐藏图标、提供应用五语关闭按钮处理。实窗与尚未验收的范围见 [设置验证](settings-validation.md)。

`decode-connectivity` 输出完整网络归属或结构化失败，不发布部分网络图；`decode-placement` 沿用源 SHA-256 绑定请求，输出封装/引脚和五语 warning。引脚定义缺失/未支持、背面裸片未支持两个新消息从实现时同步五语；网络/引脚链的缺失、类型、循环、取消和预算沿用共享消息。源网络名、元件名、ID 与偏移保持不变。CLI 五语和实际对照范围见 [网络与放置验证](brd-connectivity-placement-validation.md)。

`decode-routing` 输出走线/过孔及键合查询。过孔定义未支持、键合指/键合线未支持、走线层未定义四个诊断同步五语；必要引用、预算及取消沿用共享消息。源 profile、material、元件/引脚名保持原文。五语 CLI 的消息键/参数/对象/偏移不变，译文跟随显式 locale；真实案例和零层空过孔规范化范围见 [走线/过孔验证](brd-routing-validation.md)。

`decode-copper` 输出铜皮网格、hatch 与板框查询。网格构建失败、铜皮边界为空、矩形图层未定义三个消息同步五语；字节预算沿用共享预算消息。对象 ID、偏移、环序号和算法错误代码保留为结构化身份或技术详情，不把提前翻译的句子作为错误参数。范围与单环取消限制见 [铜皮网格验证](brd-copper-validation.md)。

```powershell
cargo test -p pomelo-core --test i18n_resources --test i18n_source --locked
cargo test -p pomelo-import --test diagnostics --locked
cargo test -p pomelo --locked
```

`i18n_resources` 检查键集合、重复键、空译文/TODO、占位符和注册表一致，并测试 locale 映射、参数错误、并发格式化和源文本保护。`diagnostics` 覆盖当前每个导入错误和五语 CLI 报告；应用测试覆盖配置替换/损坏恢复和已有诊断重译。

`i18n_source` 通过 Rust 语法树扫描当前 `child`、`label`、`tooltip`、`title`、菜单和对话框标签入口，检查直接字面文案、直接 `format!`/`to_string()` 展示、`bail!`/`anyhow!` 以及错误 Display 的技术代码。例外仅为产品名 `Pomelo`、测试 fixture/assertion；原始技术详情在明确的详情区域展示。此扫描不能发现所有经变量或自定义组件间接传入的文案，新控件/消息入口必须同步扩展规则并人工审查。注册表使动态消息键的存在与参数覆盖可检查；`cargo i18n` 仅作辅助提取。

CI 配置已加入资源/源码门禁，远端运行结果尚未取得。五语译文是开发基线，发布前还需语言审校、全部实际屏幕/状态、输入法、最小窗口、字体放大和 DPI 回归；当前原型的切换检查不代表全产品五语验收完成。

## 文字、绘图层与场景诊断

本轮新增 41 个消息键，五语共 205 条译文，覆盖字体定义、文字链/内容/尺寸、尺寸路径与所属链、空几何，以及标准绘图类别/子层和键合特殊层名称。场景保存原始自定义层名与 Message 标签，展示时按 locale 翻译；源板文字、网络名及 reference 不翻译。SceneBuilder 与文件 importer 保留 code、参数、对象身份及源位置，importer 为 warning 附加源路径。五语门禁与异常测试通过；范围见 [文字与场景验证](brd-annotation-scene-validation.md)。

桌面后台导入接入新增 5 个消息键、五语共 25 条译文：排队、取消命令、CPU 场景导入完成、场景统计与 GPU 视口待开发状态。阶段进度复用共享 ImportStage 消息键，后台保持结构化数据，不保存预翻译字符串。五语资源完整性及参数门禁通过；实窗布局验收仍待补。

走线渲染准备新增对象几何无效与 CPU 准备内存不足两个消息键，五语共 10 条译文；取消和预算复用共享消息，准备诊断保留对象 ID，源偏移未知时不伪造偏移。

## UI 设计稿落地（2026-10-03）

欢迎页、菜单、导航、工具提示、显示/检查器分栏、图层过滤、快捷键说明及状态栏使用共享 MessageKey；五语资源同步交付，源文件名、图层名、网络名与元件 reference 保持源文。主题或语言变化通知文档视口重新渲染，输入占位符更新不清空查询。毫米按钮使用跨语言通用单位符号 `mm`。解析和 GPU 诊断仍在显示时翻译，折叠分页保留严重性、诊断码、对象/偏移/路径及技术详情。五语资源及语法门禁 9 项通过；本次实窗验证主要使用简中，其他四语视觉/DPI 仍待验收。
