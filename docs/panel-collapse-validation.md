# PCB 工作区左右面板收缩

日期：2026-10-04。按用户新增需求实现，当前平台为 Windows。此记录证明面板功能的实现与下列验证范围，不代表整个 BRD MVP 或发布验收完成。

## UI 与操作

打开 PCB 后，左侧资源面板与右侧检查器/显示面板各有独立收起按钮，位于面板标题靠画布的一侧。收起后保留 `2.5rem` 窄栏及展开按钮，释放其余宽度给画布；可以同时收起两边。使用 GPUI Kit 标准 Ghost 图标 Button、主题 sidebar/border token、可访问名称和 Tooltip，不改变 UI 字体。

| 入口 | 行为 |
| --- | --- |
| 左/右面板标题按钮 | 收起对应面板 |
| 左/右窄栏按钮 | 展开对应面板 |
| Ctrl+B | 切换左侧面板 |
| Ctrl+Shift+B | 切换右侧面板 |
| 视图菜单 | 提供同名切换命令和快捷键；无 PCB 视口时禁用 |
| Ctrl+K | 左栏收起时自动展开，再聚焦顶部搜索输入框 |
| Tab / Shift+Tab、Space | 聚焦并执行标准展开按钮 |

布局属于窗口，文档切换沿用相同左右宽度和收起状态。各文档的相机、选择、搜索、面板标签和滚动状态仍独立。面板收缩不改变缩放比例、相机中心、选择或显示过滤，也不重新导入 PCB。

展开宽度在当前窗口可容纳时恢复，左栏范围为 200–440 逻辑像素、默认 256，右栏 240–440、默认 288。窗口或恢复配置过窄时夹取宽度，至少保留 360 逻辑像素画布及框架分隔预算，避免裁掉现有画布工具栏；夹取后的实际宽度可成为下一次记忆宽度。此功能提供手动独立收缩，研发计划中的进一步自动响应布局仍需单独验收。

## 代码与持久化

- `workbench/panel_layout.rs`：窗口级 `PanelLayout`、共享 Kit `ResizableState`、宽度快照、独立切换及窗口夹取。切换时清除 Kit 的子项位置缓存，按记忆宽度重建，避免隐藏一个子项后错误复用另一子项的尺寸。
- `panels/sidebar.rs`：标题组合、收起/展开按钮和窄栏展示，不拥有文档或 GPU 状态。
- `viewport/mod.rs`：条件组合可调面板与画布；搜索展开直接更新布局实体，然后聚焦输入，避免排队 Action 把焦点移回画布。
- `workbench/mod.rs`、`actions.rs`、`app.rs`、`i18n.rs`：窗口级命令、焦点恢复、快捷键、菜单及串行后台保存。
- `services/prefs.rs`：独立版本 1 `panels.json`，保存两边收起状态和展开宽度。复用配置根目录、原子替换、文件大小限制及损坏文件备份恢复；关闭/退出保存宽度，切换命令也触发保存。
- 核心消息契约与 `locales/`：六个命令键同步英、简中、繁中、日、韩。配置错误复用已有五语结构化诊断。

## 实窗结果

使用工作区内独立配置目录，未改日常偏好。Debug 的完整流程与最终 Release 的窄窗口边界分别验证；两者业务差异仅为随后扩大画布最小宽度的修正。

| 验证项 | 实际结果 |
| --- | --- |
| 左右独立及同时收起 | 标题按钮、窄栏展开、Ctrl+B / Ctrl+Shift+B 正常 |
| 画布宽度 | 初始 256/288 面板时约 895；仅左收起约 1111；仅右收起约 1143；两边收起约 1359 逻辑像素 |
| 宽度记忆 | 拖动左栏到 330，收起、展开及正常退出重开均恢复 330 |
| 搜索焦点 | 先复现 Ctrl+K 展开后焦点丢失，修正后直接输入 J1；最终 Release 最低窗口再次验证直接输入 GND 并出现结果 |
| 状态保留 | J1 的 30 个成员、实际 Pin 15220/TOP 锚点、相机和双侧收起状态正常退出重开恢复 |
| 多标签 | 原生文件对话框加入 camera_test_board；在第二文档收起左栏，切回 FPC 同样收起，J1 的选择/相机仍保留；camera 文档保持自身未选择状态 |
| 键盘 | 英文浅色最低窗口，Shift+Tab 聚焦左窄栏展开按钮，焦点框可见，Space 展开并返回画布 |
| 五语 | 真实设置切换英、繁中、日、韩、简中，面板可访问名称即时更新；浅色与简中深色均观察，五语树保存于 locale evidence |
| 最终 Release 最大恢复宽度 | 预置两栏各 440 且收起，在 1000×650 窗口依次展开，夹取为左 396/右 240，画布约 362.67×471.33，工具栏可见，43 帧提交/呈现，无 GPU 错误 |
