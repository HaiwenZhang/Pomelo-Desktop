## 硬件检查

追加范围过滤已通过硬件检查：实际 Via 的 pad 层范围在后台排序去重；隐藏所有所属层时槽孔像素消失，恢复一个所属层后重新显示，GPU 上传量和缓存创建次数不变。引脚钻孔不附加 via 范围，空 via 范围保持隐藏。绘制阶段合并连续可见区间，复用已上传实例。旧真实案例记录未覆盖这次新增的交互过滤，新版本实窗范围验收仍待完成。

显式硬件像素测试通过：旋转槽孔中心填充，沿旋转后的长轴延伸，范围外像素保留绘制前的下方画面。测试回读仅用于诊断，生产窗口没有全帧 CPU 回读。初次断言误把下方铜皮的颜色当成槽孔覆盖；改为钻孔绘制前后像素直接对照后通过。
