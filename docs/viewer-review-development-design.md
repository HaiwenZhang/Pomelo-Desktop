# 审阅功能开发设计

本文为[审阅能力规划](viewer-review-capabilities-plan.md)提供实施边界，不描述专有文件布局或商业软件操作。所有条目均为开发设计，实际交付状态另行核对。

## 模块与状态

| 职责 | 建议归属 | 边界 |
| --- | --- | --- |
| 测量、距离与路径算法 | 核心几何和交互模块 | 不依赖界面、GPU 或源格式 |
| 类型化属性与连接关系 | 核心领域模型 | 保留来源和缺失语义 |
| 测量工具与选择集合 | 文档及视口 | 每文档独立，不借用悬停状态保存 |
| 高亮和测量覆盖层 | 渲染场景及平台后端 | 使用不可变快照，不修改源几何 |
| 查询与工程信息面板 | 应用 panels | 分页、键盘导航和定位 |
| 命名视图、模板与高亮组 | 偏好服务及工作区 | 版本化、身份校验、原子保存 |
| 截图与表格导出 | 应用后台服务 | 明确输出路径、内容和失败处理 |

新增模块应落入既有职责边界，不预先建立空目录。具体类型和数据结构在实现对应批次时确定。

## 测量工具

工具状态应明确区分空闲、已选起点、预览和已完成。Escape 取消当前步骤，切换文档不把半完成操作带入另一个文档；结束、重启和清除结果分别有命令。

坐标保存为源空间数值，屏幕投影只用于展示。吸附返回类型、对象身份和位置，避免只保存屏幕点。曲线距离采用明确精度和误差边界，退化对象返回可解释结果。

对象净距先按几何类型实现，再扩展组合；优先覆盖线段、圆弧、圆形及带孔区域。资源限制、取消和不支持对象分别处理，不把无法计算返回成零距离。

## 选择与高亮

选择集合使用稳定、带类型的对象身份。追加、移除、框选及分组展开共享集合语义，避免重复成员；检查器统计和渲染高亮消费同一个快照。

持久高亮组与当前选择分别保存。组成员经过源身份检查，失效成员有计数及提示。颜色采用渲染材料覆盖，不改源图层或对象属性。

## 命名视图与历史

视图记录相机和明确列出的显示字段；源身份、数据版本和字段默认值一起定义。恢复不隐式修改全局语言或主题。

历史只记录已完成的导航动作，相邻等价项可合并；设置容量上限和前后栈规则。恢复期间不要再生成相同历史项，文件变化或对象失效时采用明确降级策略。

## 查询与工程信息

条件查询使用类型化字段和操作符，定义缺失值、单位转换、大小写及组合条件。后台执行附带取消令牌和请求身份，过期结果不发布。

结果表、画布定位和检查器共享对象身份。长集合分页或虚拟化，列宽及模板设置与结果数据分开存储。来源属性保留原名与值，界面标签使用共享翻译。

焊盘结构、物理叠层和连接拓扑分别提供模型契约，区分不存在、未知和未支持。新增导入能力先统一领域语义，再接入面板，避免源格式字段直接贯穿 UI。

## 路径长度

连接图节点和边由已有连接数据构建。分支和环存在时要求明确路径，不能把网络全部走线总长当成两端路径长度。

路径计算支持取消和规模限制，输出长度构成及未知部分。孔段长度依赖物理数据；没有足够参数时不生成看似完整的三维总长。

## 导出与保存

截图和表格导出在用户选定路径后执行，结果完成或失败都有反馈。输出配置包含尺寸、范围、单位、列和标记策略，避免未说明地包含隐藏信息。

偏好结构变更采用版本及默认值策略；读取旧文件、损坏文件和新字段时保持可恢复。新模型实施前再确认迁移影响，不在文档维护中修改持久化格式。

## 开发批次

1. 完善基础相机、拾取、源身份和显示快照的测试边界。
2. 两点测量与覆盖层，完成工具状态、单位和键盘操作。
3. 对象净距与任意多选，完成算法精度、集合及取消。
4. 持久高亮、自定义颜色、命名视图和导航历史。
5. 截图和轻量导出，完成文件对话框、预览与失败恢复。
6. 通用属性查询、模板、分页表格和 CSV 输出。
7. 逐层焊盘、物理叠层、连接关系及指定路径长度。

每个批次都要完成领域逻辑、界面接线、五语消息、必要持久化和对应验收，避免同时铺开所有入口而没有可用流程。

## 验收矩阵

| 类别 | 必验边界 |
| --- | --- |
| 测量 | 已知坐标、旋转、缩放、单位、退化和取消 |
| 净距 | 交叠、接触、孔洞、最近点、误差和不支持对象 |
| 选择 | 去重、删除、过滤、分页、失效引用和多文档 |
| 状态 | 往返、旧字段、源变化、损坏配置和退出保存 |
| 查询 | 缺失属性、类型比较、稳定排序、取消和过期结果 |
| 工程信息 | 层序、单位、来源、未知值及引用一致性 |
| 路径 | 分支、环、断开、多路径、孔段和缺失参数 |
| 输出 | 编码、转义、尺寸、覆盖确认、写入失败和清理 |
| 窗口 | 五语、DPI、键盘、焦点、长列表和持续交互 |

使用合成数据或可公开分发样本建立回归。报告分别说明 CPU、GPU 与实窗覆盖，不保留具体设计案例或原始日志。
