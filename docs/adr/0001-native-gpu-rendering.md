# ADR 0001：复用 GPUI 原生 GPU 管线

状态：当前渲染架构的决策说明，平台验收另行验证。

## 问题

PCB 画布需要在桌面 UI 中显示大量几何、文字及交互高亮，同时遵守窗口裁剪、DPI、透明度和覆盖层顺序。

## 决策

通过项目所用 GPUI fork 的 GPU 注册及绘制入口，复用当前设备和帧目标。应用维护独立的渲染 crate，Windows 使用 D3D11，macOS 使用 Metal，Linux 使用 wgpu。

共享领域场景、几何准备和显示语义，各平台维护资源创建、管线及着色器。GPUI 负责窗口与提交呈现，不承载 PCB 算法。

## 取舍

复用设备与目标可减少应用与 UI 之间的纹理桥接，并保持统一场景排序；代价是需要维护平台后端、着色器和 fork 接口的兼容性。

平台实现存在不代表跨平台视觉与性能验收完成。设备恢复、裁剪、DPI、覆盖层和资源释放需分别验证。
