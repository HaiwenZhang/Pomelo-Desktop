项目代码的许可证与字体资源的许可证分别保留。更新字体时同时维护原始署名、许可证及来源记录，不将第三方资源重新标注为项目自有代码。

## 使用与维护

字体资源用于 PCB 文字与自动标签，桌面控件的 UI 字体由应用主题及平台处理。MSDF 页按需要加载，来源记录保存资源信息及哈希；实际资源版本以该目录文件为准。

更新时核对页面清单、图集尺寸、字形布局和纹理采样约定。不能把字体距离场当普通彩色图片进行任意颜色空间转换。缺字及加载失败应走共享诊断，不通过翻译原设计文字掩盖缺口。

## 验证范围

使用合成文字检查基本拉丁字符、数字、不同语言字形、旋转、缩放、裁剪及缺字行为。CPU 布局、GPU 像素和实际窗口分别检查；资源存在不代表所有字符均有覆盖。

不在本文保留已移除字体方案的历史审计输出。当前随包资源的原始许可证、署名及来源文件继续保留。
