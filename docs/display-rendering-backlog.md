# 显示与查看功能待办

## 本轮：元件区域拾取

- Quickview 显示的放置区域可点击、悬停，选中所属元件并显示 Inspector。
- 使用实际旋转轮廓、圆弧及孔洞判断；包围盒只用于加速查询。
- 沿用绘制层次与候选切换；元件内的焊盘仍可作为独立候选。
- 关闭 Quickview 后区域退出拾取；临时关闭 Pin 显示不关闭区域拾取。
- 拾取菜单中的“焊盘与元件放置区域”共同控制这两类候选。现有查看设置和旧拾取掩码保持兼容。
- 元件定位包含真实放置边界；没有焊盘的元件也保留元件身份。
- 该能力依赖已有放置区域数据，不为缺失数据的元件补造边界。

## 待办 1：字体、动态位号与文字重叠校准

现状：源文字、多层网络名及 Placement 动态位号已接入。动态位号采用两个轴适配、接近等大时优先水平的明确近似规则。

后续工作：

- 对照字形、笔画、字高、字符间距、旋转和镜像，尤其检查 90 度附近及不同 DPI。
- 核对各级 Zoom 的显示阈值、重复间距、透明度及多层遮挡顺序。
- 保留多层名称的重叠显示语义，不能通过全局避让任意删掉下层名称。

验收：同一区域在相同图层、Zoom、DPI 下对照实机图像；明确区分字体差异、布局差异与遮挡差异。

## 待办 2：Split View


后续工作：先实测视口数量、独立相机、活动视口、图层设置的共享范围、选择同步和布局恢复，再实现对应查看操作。

验收：两个视口分别 Pan/Zoom、切换焦点、定位同一元件，并核对视图历史与测量预览。

## 待办 3：3D 渲染

现状：尚未接入原版 3D 查看流程。

后续工作：对照启动入口、相机旋转/平移/缩放、层叠和元件模型显示、2D/3D 选择联动。先确认样本提供的层厚和模型数据，不用假模型冒充源数据。

验收：用公开合成场景核对视角、比例、翻面、透明度与选择位置；不增加编辑或规则检查功能。

## 待办 4：Net Color View 文件及飞线显示

现状：整网、走线、焊盘、过孔和铜皮分类颜色已实现。原版 Net Color View 还包含 Visible rats、Colored nets，以及 Complete / Incremental / Toggle 恢复语义。

后续工作：核对 `.ncolor` 文件交换和恢复规则，补齐飞线显示及其分类颜色。不能把此项简化为隐藏整个网络的铜皮。

验收：原版与 Pomelo 使用相同配置往返导入/导出，分别验证完整、增量、切换恢复，以及隐藏/恢复后颜色状态。

## 待办 5：SVG / PNG 标注导出的最终验收

现状：暂停前已有一轮开发中的接入代码：源 MSDF 字形、显式 ANSI 笔画、网络名和 Placement 位号传入导出；绘制顺序按画布类别排序；铜皮填充和文字共用孔洞遮罩。MSDF 标注以声明的输出分辨率生成透明 PNG 图块并嵌入 SVG，几何仍使用 SVG 路径，不依赖系统字体。

已有 12 项快照回归通过，覆盖源文字、逻辑像素阈值、DPI、层次遮挡、Zoom、铜皮名称透明度与重叠孔洞。这些检查不等于完成完整导出验收。

后续工作：

- 对照真实 GPU 画布与导出的 MSDF 边缘、颜色、alpha 和裁剪像素。
- 验证 ANSI 覆盖、旋转、镜像、Placement 标注及多种 SVG 查看器。
- 用公开合成场景实际操作保存 SVG/PNG，检查视口和整板两种范围。
- 核对测量文字、选中/悬停反馈、未填充焊盘及复杂曲线的导出一致性。
- 再评估输出体积、取消响应和超大图像预算，不据当前单元测试声明逐像素一致。
