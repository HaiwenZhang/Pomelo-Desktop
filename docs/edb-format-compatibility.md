# EDB DEF 格式兼容

导入器按文件自带的类型表解码，不以软件发布年份或文件头版本白名单选择固定布局。已验证的内部格式版本为 `7.3`、`8.6`、`9.0`、`9.5`、`10.6`、`12.1`。结构兼容的其他数字版本也会尝试导入；这不等于已验证所有历史或未来软件版本。

## 样例中观察到的规律

对九个本地文件进行比较，覆盖两个板型；原始文件与设计名称不进入仓库。

| 内部版本 | 样例数 | 类型表项数 | 相比前一组的变化 |
|---|---:|---:|---|
| 7.3 | 2 | 43 | 布局、走线及元数据的较短字段表 |
| 8.6 | 2 | 44 | 追加布局、走线和元数据字段及一种类型 |
| 10.6 | 2 | 49 | 追加布局、元数据字段及多种类型 |
| 12.1 | 3 | 49 | 扩展两种附加类型的字段 |

已消费的层、网络、元件、焊盘、过孔及解析几何字段，在这些样例中保持相同的类型编号、字段编号和编码。两个板型分别保持相同的对象数量，并通过引用完整性、有限坐标、铜区网格和搜索索引检查。

后续批次扩展到三个板型的 18 个文件，新增 `9.5` 归档，全部完成导入并建立搜索索引。两个文件各报告两项无效镀层比例，其余 16 个文件无诊断；同一板型在各版本中的对象数量保持一致。该批次没有逐文件执行三维渲染。

## 归档结构

数值使用小端序。归档由标志字节 `0`、带 `u32` 字节长度的 UTF-8 `Hdr` 文本、类型表、根对象和结束标记组成。类型表用类型编号及一组 `(字段编号, 编码)` 描述对象，字段值按声明顺序存储。对象通过字段编号访问，不能假定所有版本有相同字段数量或声明顺序。

| 编码 | 已实现的值 |
|---|---|
| 0 | 一个字节 |
| 1 | 有符号 32 位整数 |
| 2 | 64 位浮点数 |
| 3 | 64 位已求值物理量及带长度的表达式文本 |
| 4 | 带长度的 UTF-8 文本 |
| 5 | 带类型编号的对象，编号 `-1` 表示空值 |
| 6 | 带数量和元素编码的同类型数组 |
| 7 | 每项分别带编码的属性集合 |

编码 `8` 已在 TEDB 的多边形实例中验证：负载为 `u64` 元素数量，随后连续存储该数量的 `f64`，没有逐元素类型标签。读取时检查数量、剩余字节、取消和总值数量预算。

## 钻孔和非零元件变换

另一个 `9.0` 归档有 44 项类型声明，包含元件局部坐标、非零平移和旋转。引脚、孔偏移、焊盘偏移及元件自有几何会转换到板坐标；镜像元件按局部 Y 轴反射后旋转和平移，非单位缩放仍明确拒绝。

镀层比例既可为数字，也可为 `plt='100'`、`plt='20'` 等数字文本。零表示无镀层，正的合法比例保留镀层标记；非有限值或无法解析的表达式会报错。一个较旧样例中有两项越界负比例，导入保留几何并报告镀层未确定，不虚构孔壁。未放置的库定义不参与几何准备。

圆孔、圆端槽及方角矩形孔保持各自轮廓；任意闭合多边形孔保留共享的原始路径和填充轮廓，不用外接矩形代替。旧序列化数据的 `custom` 默认为空，仍按原来的解析孔形读取。二维孔显示、拾取和 SVG 导出使用实际孔形。三维预览按显示要求把所有 Via 画成实心柱体，不从其焊盘、铜区和走线挖孔；Pin 的钻孔仍参与切孔。三维使用示意层间距和镀层厚度，不代表制造实体。

丝印和阻焊层图形保留为可控制的辅助绘图层；填充图形目前显示边界，并给出提示。

## 兼容规则

- 正常解析 `Hdr`，要求版本为正数主版本及数字次版本，并显式声明 `Encrypted=false` 或 `EncryptionLevel=0`；同时出现时两者都须表示未加密。记录实际版本。
- 核心类型第一次实例化时检查所需字段的编号和编码。缺失或改变的核心字段会明确报错。
- 根据归档自身的类型表读取新增字段和对象，允许类型表及字段声明重新排序。
- 未使用的新类型声明不会导致拒绝；实际遇到未知编码时拒绝，不能在未知负载长度上跳读。
- 保留截断、重复字段、深度、对象数量、引用和几何检查。

未见版本的兼容依据是结构相同，并非对新增字段语义的猜测。加密归档、改变核心语义的新几何和未知线格式仍需要独立样例与实现。本功能输出当前查看器支持的板级几何，不代表完整复现 EDB 全部对象或物理叠层数据。

## 回归验证

常规合成测试覆盖已见及未见的版本号、新字段、新对象、字段重排、核心结构冲突、未知编码、加密及截断：

```sh
cargo test -p pomelo-import --lib formats::hfss --locked
```

完整本地样例回归不包含于仓库，使用环境变量指定根目录：

```sh
POMELO_EDB_CASES=/path/to/local/cases cargo test -p pomelo-import --test hfss_case edb_archive_versions --locked -- --ignored
```

这些检查证明 CPU 导入与搜索可用；不代替各平台的实际画布验证。

## PyEDB TEDB 回归

对本地 TEDB 的 35 个 `edb.def` 执行导入和搜索索引检查，34 个非空数据库通过。`test_107.aedb` 没有铜层、图形或焊盘，返回 `NoGeometry`，不生成虚构板框。

新增覆盖中心/宽/高矩形、平头/延伸/截断走线、镜像元件、普通分组、装配等辅助层、紧凑多边形实例、隐式焊盘层使用和 pin-group 元数据。复制到其他层却保留旧父引用的 void，仅在新层有唯一且几何相同的父多边形时重新绑定，并给出诊断；没有匹配或存在歧义时拒绝。

多 cell 归档显示第一个 cell 并明确提示，其余 cell 不合并到同一块板。仿真点端子和文字注释暂不显示并给出提示。非铜填充图形显示边界。

```sh
POMELO_HFSS_TEDB=/path/to/pyedb/tests/example_models/TEDB cargo test -p pomelo-import --test hfss_tedb --locked -- --ignored
POMELO_HFSS_TEDB=/path/to/pyedb/tests/example_models/TEDB cargo test -p pomelo-render --test board3d imported_polygon_vias --locked -- --ignored
```

`padstacks.aedb` 的八边形孔检查原始八条边、孔中心覆盖及外接矩形角点不属于孔；三维检查该文件的实心 Via 均能准备且没有警告。常规合成测试检查自定义孔序列化、旋转/镜像拾取、孔切除面积及轮廓镀层；WARP 像素回归检查二维任意孔形和三维 Via 实心显示。
