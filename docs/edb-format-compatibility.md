# EDB DEF 格式兼容

导入器按文件声明的类型表解码，不以软件发布年份或文件版本白名单选择固定布局。档案版本保留在源元数据中；能读取兼容结构并不等于支持全部 EDB 对象与物理层叠语义。

## 解码与资源约束

类型表以字段编号和编码描述对象。解析检查头部、加密标记、字段声明、对象引用、长度、嵌套深度和总值数量。核心字段缺失或编码冲突、未知线格式、截断和不合法引用返回明确错误。未使用的附加字段可以按其声明读取，不能猜测未知负载长度并跳过。

支持显式未加密的 `Encrypted=false` 或 `EncryptionLevel=0` 头部；两者同时出现时都必须表示未加密。加密档案不受支持。

## 几何与显示

元件局部坐标、焊盘偏移、孔偏移和自有几何经平移、旋转与镜像变换到板坐标。非单位元件缩放明确拒绝。镀层比例可使用数字或可解析的数字文本；越界或无法解析的值产生诊断，不虚构镀层厚度。

圆孔、圆端槽、矩形孔和任意闭合多边形孔保留各自轮廓。多边形孔不使用外接矩形代替。二维显示、拾取和 SVG 导出使用实际孔形。三维预览将 Via 显示为实心柱体，不从其焊盘、铜区和走线挖孔；Pin 钻孔仍参与切孔。示意层间距与镀层厚度不代表制造实体。

隐式焊盘层、分组、紧凑多边形实例和辅助绘图层分别解析。复制的空洞仅在存在唯一、几何匹配的父轮廓时重新绑定；歧义引用拒绝导入。多 cell 档案显示第一个 cell 并给出提示；未显示的仿真端子、文字或填充图形通过诊断说明。空数据库返回 `NoGeometry`。

```sh
cargo test -p pomelo-import --lib formats::hfss --locked
cargo test -p pomelo-render --test solid_prepare --test board3d --locked
```
