# 板框 GPU 接入与铜皮批次准备

日期：2026-10-02。当前 Windows 正式视口显示走线、圆弧和板框。铜皮完成 CPU 上传数据准备，**尚未接入正式 GPU 覆盖合成**，不能将本记录视为铜皮画面验收。

## 板框

`PreparedTracks::build_with_outline()` 直接借用走线与板框两个集合，不复制完整 Segment 数组。实例保留源对象、源图层和组合源索引；flags bit 2 区分板框，板框形成独立批次并在走线之后绘制。板框使用主题前景色，避免源层 ID 与走线相同时被错误染色。

128 字节实例布局及 HLSL 线段/圆弧算法继续复用；零宽板框以一个物理像素的 hairline 显示。走线与板框共同受实例数量和 CPU 输出预算约束；其上传继续按每帧最多两个 16,384 实例块执行。

CPU 检查覆盖类别、源身份、源顺序与合并预算。RTX 5080 硬件像素测试新增同层红色走线和中性方形板框，确认板框独立着色与零宽覆盖；既有导航、精度、裁剪、圆弧及分批上传检查继续通过。

![板框、线段与圆弧诊断图](gpu-validation/outline-pixels.png)

像素测试使用离屏诊断 CPU 回读；生产窗口没有全帧 CPU 回读。记录见 [outline-pixels.json](gpu-validation/outline-pixels.json)，不等同于真实 PCB 窗口截图。

## 铜皮 GPU 数据准备

新增 `pomelo-render::copper::PreparedCopper`：16 字节高低位顶点、重定位后的全局索引、按层排序的批次。顶点/索引保留源顺序，批次保留对象/层/网络/源索引、外环边界和曲线标志。`outer_indices()` 与 `hole_indices()` 分别表达外环及孔洞覆盖，不提供将两者合并填充的批次范围。

孔洞沿用独立三角化的源网格；相交孔洞不能通过 XOR 再次填实。后续 GPU 必须计算外环覆盖减去孔洞覆盖的并集，并保留背景中已绘制的其他图元。曲线标志保留，真实曲线边缘覆盖与抗锯齿仍需后续 shader 验证。

默认准备预算：16,000,000 顶点、48,000,000 索引、250,000 铜皮和 512 MiB 输出。所有总量与字节预算在分配前检查；每 1,024 顶点/索引检查取消。校验非有限/不可上传坐标、三角形计数、索引越界、外环索引误指孔洞及孔洞索引误指外环。错误复用稳定 PrepareError 和五语诊断，保留失败对象及导入路径。

该预算只约束准备输出，**不是整个进程 RSS 或 GPU 总预算**。不可变准备结果在后台生成并以 Arc 由文档和视口共享，导航不重新准备。
