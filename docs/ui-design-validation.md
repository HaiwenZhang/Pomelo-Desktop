## 2026-10-03 后续补齐

修复退出后检查器和相机回到旧状态的问题：查看快照直接进入后台串行保存，退出等待不再依赖主线程分发。真实 LPDDR4 的清空选择、翻板、不同缩放与走线选择，经 Ctrl+Q 和标题栏关闭后均能恢复；与 USBC 同窗退出也保持各自着色、过滤和相机独立。具体范围及退出超时边界见 [退出恢复验证](view-exit-validation.md)。

文档标签已显示真实导入格式徽标，命令栏补齐 Ctrl O / F2。长名称标签和标题受宽度约束，原生控制按钮在最低宽度仍可见；日文拾取名称整项换行。应用按钮提示改为 GPUI 所属元素管理生命周期，修复打开文件、打开设置与关闭标签后的旧提示残留。同窗 USBC / LPDDR4 的快捷键切换及独立视图已实际验证，见 [标签、长名称与提示验证](workbench-tabs-validation.md)。这不表示 DPI、全键盘或逐像素验收通过。

画布悬浮工具栏进一步对齐两张工作区设计图：深浅主题均为深色表面，浅色文字/图标、绿色选中态、分组线和实际居中。通过 Kit 自定义按钮样式及产品主题色实现；工具栏按下和滚轮事件不再穿透到画布。实窗验证放大、平移、适应、双次翻转均保持 GND 选择及真实统计，1000×650 深色窗口下与比例尺没有重叠，具体证据见同一记录。

最近文件新增可选 `presentation`：保存最后一次成功导入的源物理图层数和 Base64 PNG，沿用 `recent.json` 的版本 1、有界读取与原子替换。旧文件不含该字段仍可读，缺少预览显示占位图；日期取真实打开时间，按本地日历显示今天/昨天/月日/年月日。资源与诊断同步五语。PNG 保持标准 RGBA，送入 GPUI 时转换为 BGRA；单图 192×128、压缩字节不超过 128 KiB，最多 20 项。解码在后台进行，同时限制尺寸、字节和内存。坏预览保留历史入口并提供本地化 warning；过期解码结果不能恢复已移除项或覆盖重新导入的数据。层数、图像均为历史快照，不表示重新检查了当前磁盘文件。

检查器已把名称、源 ID 与统计改为左右双列，标题保留真实源名称与类型；统计移到连接对象之前。分页成员使用带图标及定位箭头的卡片，继续使用真实对象 ID 和原有定位命令，未虚构示例引脚。其余复杂源字段保留完整本地化详情。图层行新增导电层/平面层/介质层/未知类型说明，依据源 `LayerFunction`；不根据 GND/PWR 名字猜测电源、地或信号层。

最初补齐通过应用 50 项测试、i18n 9 项门禁、工作区 Clippy 与 Windows debug 构建。6 项新增测试覆盖 PNG 通道往返、损坏/尺寸/字节限制、旧历史兼容、元数据保存与 20 项历史读取、当地午夜及跨年日期、过期缓存回调。首次复验曾遇到窗口工具的 `foreground window did not report a process id`；后续重建工具会话并重新选择窗口后恢复正常，新增布局和重启预览已取得下表所列实窗证据。未修改源 BRD 文件。

进一步对照实窗修正欢迎页拖入框的虚线边界、48 像素功能图标与分隔线；窄窗口下文件入口和最近列表改为上下排列，避免名称被时间及缩略图挤成两个字符。检查器顶部增加清除选择按钮。比例尺取消整数舍入，保留小数刻度，修复高倍缩放显示“0 毫米”；画布宽度不足 640 逻辑像素时上移比例尺，避开悬浮工具栏。新增一个回归覆盖毫米/mil、不同缩放范围及投影长度一致性，应用测试增至 51 项。

设计稿的单图层走线/过孔/焊盘 Checkbox 已接入正式绘制、拾取及视图保存；图层名称负责展开，眼睛负责整层显隐。列表改为支持不同高度的 GPUI `ListState`/`list`，保留虚拟化与共用滚动条。类别恢复后无需重新上传几何，真实 BOTTOM 过滤及重启恢复已实窗检查；范围与硬件证据见 [单图层过滤验证](layer-primitives-validation.md)。

检查器四模式按钮改为按完整文字自然宽度分配空间，空间不足时换行，取消等宽零基准造成的省略。最新英文实窗在默认窗口下四个完整名称同排，1000×650 下 Component 独占第二行；实际点击 Component 后选中状态更新、旧选择清除，点击 Object 可切回。简中继续保持四按钮同排。Windows debug 构建及工作区全目标/全特性 Clippy 通过；此项为布局修正，没有新增镜像样式的测试。

网络着色已从禁用占位接入正式 D3D11 绘制，按 Web 203 项调色板及源网络 ID 取色；网络列表与检查器标记使用同一表。走线/圆弧、解析及自定义焊盘/过孔、铜皮已支持，零网络保留源层色，钻孔/绘图/文字保持原材料。选择高亮优先，切换不增加静态几何上传，模式按文档持久化；硬件及真实板证据见 [网络着色验证](network-colors-validation.md)。

继续补齐设计稿的检查器定位/清除操作区、着色按钮主色选中态及画布的真实选择名称提示。图层 Checkbox 改为自然宽度、整项换行，修复最小左栏中的日文拆字。五语工作区对命令栏、模式名称、图层选项及选择操作区进行了实际检查；日文另验证 GND 搜索、下一页与显示面板，英文实际平移后重新定位 GND、清除并检查禁用状态。具体范围见 [工作区五语与检查器验证](workbench-i18n-validation.md)，不代表完整五语全流程已经通过。
