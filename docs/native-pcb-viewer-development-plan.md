# 后续开发计划

本文记录 Pomelo 自身的改进方向。现有功能见[功能说明](viewer-features.md)，具体审阅功能见[审阅能力规划](viewer-review-capabilities-plan.md)。规划项不表示已经实现，也不自动启动产品代码修改。

## 优先顺序

| 顺序 | 方向 | 交付重点 |
| --- | --- | --- |
| 1 | 可靠的查看基础 | 兼容诊断、显示精度、取消、恢复与平台稳定性 |
| 2 | 日常审阅 | 测量、多选、高亮、命名视图与本地输出 |
| 3 | 工程信息 | 属性查询、焊盘逐层结构、叠层及连接关系 |
| 持续 | 性能与可访问性 | 大型场景、键盘操作、DPI 和五语界面 |

## 基础改进

完善不支持对象和部分导入的提示，明确源版本与实际读取范围。持续修正曲线、孔洞、文字、层序和高倍缩放的边界，避免将视觉近似当作工程精确结果。

完善导入取消、快速切换、重载和退出保存的任务时序。检查设备恢复、配置失败以及缓存释放，使错误可理解、操作可恢复。

## 性能与平台

优化场景准备、GPU 上传和空间查询，按可见范围工作；分别观察 CPU、GPU 和进程内存。优化前后使用相同统计口径，性能数字留在私有验证环境，公开说明覆盖方法及局限。

Windows、macOS、Linux 分别验证窗口、键盘、DPI、字体与图形驱动。跨平台检查维护相同画面语义，不用一个平台的构建结果代替其他平台实机验收。

## 交付标准

每项功能需完成领域模型、后台处理、界面操作、五语消息、持久化策略及失败路径；仅有模型或解析字段不算交付。几何算法使用可独立计算的合成测试，界面使用实际窗口操作，GPU 使用平台像素检查。

新增能力遵守只读边界，不写回源设计。当前规划不包含设计编辑、DRC、规则求解、3D、协作或自动化审阅。详细模块和实施顺序见[审阅开发设计](viewer-review-development-design.md)。
