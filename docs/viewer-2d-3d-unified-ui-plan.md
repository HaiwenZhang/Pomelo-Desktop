# 2D / 3D 统一查看界面开发计划

制定日期：2026-11-10。目标用户是 PCB Layout 工程师和 SI/PI 工程师。功能来源见 [HFSS 3D Layout 三维显示调研](hfss3d-layout-3d-rendering-reference.md)，渲染基础见 [PCB 三维渲染方案](pcb-3d-rendering-design.md)，2D 审阅能力见[审阅能力规划](viewer-review-capabilities-plan.md)。本计划只描述待开发内容，不代表已交付功能。

## 1. 目标与范围

当前 2D 与 3D 各有一套画布控件：3D 在画布顶部放显示方式和 Z 倍率，在底部放适配和三个视角按钮，叠层假设以文字压在画布上；图层面板在 3D 下仍是 2D 的内容。本计划把两种模式收敛为同一套面板、同一条画布工具条和同一份显示状态，并补齐 3D 查看内部结构所需的操作。

范围内：

- 画布上只保留一条底部图标工具条和右上角视图立方体；其余控制进入左右面板。
- 图层 × 对象类别矩阵、可见性视图、网络分组与隔离，2D 与 3D 共用。
- 3D 显示模式、Z 拉伸、选择反馈、过孔使用段与残桩、3D 测量和图像输出。
- 2D 的活动层与单层模式、指针处叠层、相邻平面叠显、网络长度表、引脚间路径长度。

范围外：设计编辑、规则检查、阻抗或串扰计算、网格与场结果、动画、刚柔弯折、外部三维组件。剖切平面本期不做，列入第 6 节。

## 2. 设计约定

1. **一份状态。** 图层显隐、类别显隐、颜色、透明度、网络显隐、选择与拾取过滤由 `BoardDisplay` 及选择状态统一持有；3D 只增加相机、显示模式和 Z 拉伸。
2. **同一位置同一功能。** 顶部工具栏不随模式变化。底部工具条在两种模式下分组一致：视图 / 显示 / 工具。
3. **画布保持干净。** 工具条只放图标，悬停给出名称、快捷键或小浮层；需要多个参数的功能在右侧面板提供完整控件。
4. **显示不等于物理。** Z 拉伸、透明度和线框只改变显示。源文件未提供的层厚使用显示假设，所有依赖它的读数都标注来源。
5. **只读。** 任何操作不写回设计文件，不给出规则结论。

### 底部工具条

| 分组 | 3D | 2D |
| --- | --- | --- |
| 视图 | 适配（有选择时适配选择）、框选缩放、翻面、上一个视图 | 同 3D |
| 显示 | 显示模式、Z 拉伸 | 单层模式、相邻平面叠显、隔离选中 |
| 工具 | 测量、隔离选中、复制图像（剖切位预留） | 测量（两点 / 折线 / 净距 / 路径长度）、框选对象、复制图像 |

## 3. 现状与差距

| 方面 | 现状 | 差距 |
| --- | --- | --- |
| 3D 画布控件 | 顶部“实体 / 透明观察 / Z 倍率”，底部“适配 / 顶 / 底 / 轴测”，叠层假设文字浮在画布上 | 与顶部工具栏的适配重复；没有标准方向全集、适配选择和视图历史 |
| 3D 状态 | `View3d` 仅存在于视口内，不进入 `ViewState` | 重新打开文档后丢失相机、显示方式和 Z 倍率 |
| 类别显隐 | `LayerPrimitives` 提供逐层走线、过孔、焊盘三类 | 缺铜皮和元件两列，没有逐格填充/线框，没有逐层透明度 |
| 3D 透明 | `materials()` 用一个全局 `transparent` 开关乘以全局不透明度 | 没有 Default / Sketch / Solid 三种模式，没有选中实体化和未选淡化强度 |
| Z 倍率 | 着色器对 Z 统一乘倍率，层间距由 `PreviewStackup` 等分 | 无法只拉伸介质；没有连续滑块和实时预览 |
| 相机 | `CameraView3d` 有 Top、Bottom、Isometric，正交投影 | 缺前后左右、正二测、正三测和视图立方体 |
| 层叠 | 模型层没有厚度字段，3D 使用 1.6 mm 板厚等分 | 介质层不可见、不可单独控制；假设来源只以一行文字表达 |
| 网络信息 | 检查器给出二维中心线总长和对象计数 | 没有各层长度、过孔使用段、残桩、相邻平面；没有网络分组和显隐 |
| 2D 单层查看 | `ShadowMode` 与 `active_layer` 已支持非活动层变暗 | 没有工具条入口和逐层切换快捷键 |
| 3D 审阅 | 进入 3D 时测量、框选等审阅工具被停用 | 3D 下没有测量和图像输出 |

## 4. 阶段计划

规模为相对估计：S 约一周内，M 一至两周，L 两周以上。每个阶段独立可发布。

### 阶段 1：状态统一与画布骨架（M）

交付：

- `ViewState` 增加 3D 查看状态：相机、显示模式、Z 拉伸倍率与拉伸对象。提升 `schema_version` 并提供旧文件迁移；缺失时使用默认值。
- 底部图标工具条组件，2D 与 3D 各一份配置；悬停提示和小浮层使用同一个组件。删除 3D 顶部工具条、底部文字按钮和画布上的叠层说明。
- 适配命令在有选择时适配选择，否则适配整板；框选缩放和视图历史覆盖 3D 相机。
- 状态栏显示模式、活动层和指针所在层；层叠假设移到图层面板底部的标签和层叠设置入口。

主要位置：`pomelo-core/src/view_state.rs`、`viewport/view3d.rs`、`viewport/view3d/controls.rs`、`viewport/layout.rs`、`viewport/navigation.rs`、`services/preferences/view_state.rs`。

验收：两种模式切换后顶部工具栏无变化；3D 相机、模式和倍率随文档保存恢复；旧版查看状态可读取；键盘可到达工具条每个按钮。

### 阶段 2：视图立方体与标准方向（S）

交付：

- `CameraView3d` 扩展为顶、底、前、后、左、右、等轴测、正二测、正三测；“翻面”在顶底之间切换并保持板内位置。
- 右上角视图立方体：点击面、棱、角切换方向，拖动立方体等同旋转；切换使用短动画，可在设置中关闭。
- 2D 与 3D 切换时保持同一板内位置和缩放范围。

主要位置：`pomelo-core/src/interaction/camera3d.rs`、新的 `viewport/view3d/view_cube.rs`、`viewport/motion.rs`。

验收：九个方向的朝向用合成长方体核对；底视方向左右不镜像错误；立方体朝向与方向三轴一致。

### 阶段 3：图层矩阵与可见性视图（L）

交付：

- `LayerPrimitives` 扩展为五类：铜皮、走线、焊盘、孔、元件；每格三态：填充、线框、隐藏。增加逐层不透明度。2D 与 3D 的材质和拾取都读取同一份设置。
- 图层面板改为矩阵：列头整列切换，双击层名只看该层，介质开关控制介质层行。非物理层折叠为一组，在 3D 下标明仅 2D 显示。
- 可见性视图：内置全部、表层、信号层、电源与地；用户可保存当前图层与网络显隐组合。与现有命名视图区分：可见性视图不保存相机。
- 2D 单层模式入口：工具条按钮、PageUp / PageDown 逐层切换、非活动层亮度滑块，复用 `ShadowMode`。

主要位置：`pomelo-core/src/display.rs`、`pomelo-core/src/review/views.rs`、`viewport/layer_panel.rs`、`panels/layers.rs`、`pomelo-render/src/scene/board3d.rs` 的 `materials()`、2D 提交与拾取可见性路径。

验收：同一设置在 2D 和 3D 的可见对象集合一致；隐藏对象不可拾取；旧的三类设置迁移后显示不变；四个内置视图在无平面层、仅两层等板上结果合理。

### 阶段 4：3D 显示模式与选择反馈（L）

交付：

- 三种显示模式：默认（采用逐层不透明度）、线框、实体。逐格线框设置在默认和实体模式下仍生效。
- 线框绘制：为实体管线增加轮廓边绘制，三个后端一致。
- 选择反馈：未选对象淡化强度、悬停预选、线框中选中对象实体显示、首选与追加选择颜色。
- “隔离选中”：只显示选中网络或元件及其所在层，再次点击恢复之前的可见性。
- 重叠对象循环选择在 3D 中按射线命中顺序工作。

主要位置：`pomelo-render/src/backend/solid_pipeline.rs`、`backend/wgsl.rs`、各后端 `driver/solid.rs`、`scene/board3d.rs`、`viewport/view3d.rs`、`viewport/hover.rs`、`panels/display.rs`。

验收：半透明叠加在多个角度没有明显排序错误，已知限制写入验证文档；三个后端的线框像素测试通过；淡化不影响拾取；隔离与恢复不丢失用户原有显隐。

### 阶段 5：Z 拉伸与介质显示（M）

交付：

- Z 拉伸改为连续滑块加预设，拖动时实时预览。
- 拉伸对象两种：**仅介质**（默认，金属层保持厚度，只拉开层间距）和**介质和金属**（整体放大）。实现上把统一的 Z 倍率换成逐层高度映射：顶点携带所属层及层内相对高度，着色器按映射表求显示高度；包围盒、裁剪、拾取射线和适配使用同一映射。
- 介质层作为可显示对象：按层间距生成介质板体，受“介质”开关和逐层不透明度控制；介质隐藏时过孔在可见层之间连续显示。
- 层叠设置：显示各层厚度及来源（源文件 / 显示假设），允许调整仅用于显示的假设值。

主要位置：`pomelo-render/src/scene/board3d.rs`、`scene/board3d/paging.rs`、`backend/wgsl.rs`、`pomelo-core/src/geometry3d/`、`viewport/view3d.rs`、`panels/display.rs`。

验收：仅介质模式下铜厚的屏幕尺寸不随倍率变化；跨层孔段随映射拉伸且不断开；两种模式下拾取与高亮位置一致；倍率不改变任何测量读数。

### 阶段 6：网络分组与 SI 信息（L）

交付：

- 网络页：正则搜索；分组为差分对、按前缀的总线、电源与地、全部。差分对由名称推断时明确标注来源；源文件提供真实分组时优先使用。
- 网络显隐：显示、隐藏、仅显示它、全部显示；状态进入 `BoardDisplay`，2D 与 3D 共用。
- 检查器网络卡片：各层走线长度、过孔列表及每个过孔的使用层段、残桩层段、走线层的相邻平面层、引脚列表。残桩由过孔位置上的走线端点所在层推断，说明判定依据；长度为二维中心线长度，不含孔段。
- 3D 中过孔使用段与残桩用不同样式绘制，可在显示页关闭。

主要位置：`pomelo-core/src/selection.rs` 及新的网络统计模块、`pomelo-core/src/display.rs`、`panels/selection_details.rs`、`panels/search.rs`、`viewport/search.rs`、`scene/board3d.rs`。

验收：统计在后台计算且可取消；合成网络覆盖无过孔、盲埋孔、分支和环；残桩判定对未连接走线的过孔不误报为“无残桩”；大网络（电源、地）不阻塞界面。

### 阶段 7：2D 增强（M）

交付：

- 指针处叠层：右侧面板显示指针位置每个物理层是走线、铜皮、焊盘还是无铜，以及所属网络。
- 相邻平面叠显：选中走线时叠加上下相邻平面层的铜皮轮廓。只做显示，不标记跨分割。
- 网络长度表：底部可折叠面板，列出一组网络的总长、各层长度、过孔数及与基准网络的差值；可排序，可导出 CSV。3D 模式下同样可用。
- 引脚到引脚路径长度：加入测量工具组；处理分支、环和无连接，先确认路径再给出长度。
- 搜索框支持输入坐标跳转。

主要位置：`viewport/hover.rs`、`pomelo-core/src/interaction/picking_index/`、`viewport/review.rs`、`viewport/review_panel.rs`、`viewport/review_export.rs`、`workbench/panel_layout.rs`、`panels/search.rs`。

验收：指针处叠层的结果与逐层拾取一致；长度表与检查器数值一致；底部面板的开合状态随窗口保存；路径长度在多路径时要求用户选择而不是静默取最短。

### 阶段 8：3D 测量与图像输出（M）

交付：

- 3D 两点和多段测量，吸附焊盘中心、过孔中心、线端点和层表面；读数给出距离及 ΔX、ΔY、ΔZ。ΔZ 依赖层厚假设时标注“假设”。
- 复制当前视口图像到剪贴板；PNG 导出支持 3D 视口，沿用现有“移除设计名称”和标记选项。
- 3D 下恢复审阅面板中与几何无关的部分：选择集合、高亮组。

主要位置：`viewport/review.rs`、`viewport/review_overlay.rs`、`viewport/review_export.rs`、`pomelo-core/src/interaction/camera3d.rs`、`viewport/view3d.rs`。

验收：同一对点在 2D 与 3D 的平面距离一致；Z 拉伸不改变读数；导出图像与屏幕显示的可见集合一致；三个平台的剪贴板写入分别验证。

## 5. 顺序、依赖与风险

阶段 1 是其余阶段的前提。阶段 2 和阶段 3 可并行。阶段 4 依赖阶段 3 的逐格三态和逐层不透明度。阶段 5 依赖阶段 4 的材质路径。阶段 6 可在阶段 3 之后任何时间开始，阶段 7 依赖阶段 6 的统计。阶段 8 依赖阶段 5 的高度映射。

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 半透明排序 | 默认模式下多层平面叠加出现错误遮挡 | 先按层序由远及近绘制，记录已知限制；不承诺与顺序无关的透明 |
| 逐层高度映射 | 改动顶点格式、分页包围盒和拾取，三个后端都受影响 | 先在一个后端闭环并用合成层叠做像素与拾取测试，再移植 |
| 层厚缺失 | Z 向读数和残桩长度没有物理意义 | 模型增加可选厚度及来源字段；未知时只显示层段，不显示长度 |
| 残桩与差分对的推断 | 误报会损害 SI 用户的信任 | 标注推断来源，提供关闭选项，文档写明判定规则 |
| 查看状态迁移 | 旧文件无法恢复 | 每次结构变更提升版本并保留迁移测试 |
| 面板密度 | 矩阵在窄面板和五种语言下溢出 | 列头使用图标加提示，面板最小宽度按最长语言核对 |

## 6. 未来可能实现的功能

以下不在本计划的阶段内，按需要另行立项：

- **剖切平面**：单个或多个平面，X / Y / Z 及自定义方向，拖动手柄和数值定位，翻转保留侧，穿过选中对象，正对截面查看；截面按层着色填充。底部工具条的工具组已为它预留位置。
- 层间测量和面积测量。
- 2D 与 3D 分屏联动：同一选择、同一可见性，相机可选同步。
- 命名视图保存 3D 相机和显示模式。
- 读取源文件的真实层叠厚度和材料，多区域层叠。
- 元件包络（按封装高度）和外部三维模型。
- 材质着色（阻焊、丝印、表面处理）和透视投影。
- 三维模型导出。
- 相邻平面跨分割标记、条件查询与查询模板。
- 背景、网格、连接点、飞线等辅助显示的 3D 版本。

## 7. 通用完成标准

每个阶段都需要：五种语言的消息；查看状态的保存、恢复与迁移测试；后台计算可取消且不阻塞界面；D3D11、Metal 和 wgpu 的结果分别验证，未验收的平台在交付记录中列出；对应的验证文档更新；公开文档与测试不包含本地案例的名称、截图或统计。
